# Tandem

Una MacBook Pro y una PC Windows funcionando como un solo puesto de trabajo: los monitores se reparten con un clic, hay un solo teclado y mouse (Deskflow), la PC se enciende y apaga a distancia, y las dos máquinas comparten un enlace propio por cable con Wi-Fi de respaldo.
