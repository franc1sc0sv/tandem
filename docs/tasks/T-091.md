# T-091 — Pairing test without a paused clock using real QUIC

## Context

`pairing::tests::nobody_confirming_times_out_without_saving` always failed in WSL outside the sandbox (`Connection(TimedOut)` in 0.06 s) and passed in CI. The `scripts/claude/gate-commit.sh` hook runs the full suite outside the sandbox, so it blocked commits and other commands of the session (see `docs/dev/HANDOFF.md`).

The cause is the combination of `#[tokio::test(start_paused = true)]` with real QUIC connections over loopback: with the clock paused, tokio jumps to the next timer as soon as no tasks are ready, and the handshake limit expired before the UDP packet arrived.

## Scope

Use the real clock in that test, with a short confirmation wait on the Mac (300 ms) and a long one on the PC. No changes to production code.

## Acceptance criteria

- [x] `cargo test -p tandemd --lib pairing` passes stably outside the sandbox in WSL (6 of 6 runs).
- [x] The test still checks that without confirmation the Mac fails by timeout, the PC fails and no trust is saved.

## Notes

- Only one test changes; production behavior is not touched.
- Removing the mention of this known failure from `docs/dev/HANDOFF.md` is left for whoever updates the handoff.
