# T-022 — Input capture on macOS

## Scope

`tandem-input::macos::capture`: active CGEventTap on kCGHIDEventTap on its own thread, swallow events while focus is remote, freeze and hide the cursor, re-enable the tap, detect Secure Event Input, TCC permission flow.

## Acceptance criteria

- [x] Compiles on macos CI.

## Notes

- Structure: `translate` (CGEvent read → `InputEvent` + swallow/pass/re-enable) and `grab` (taking the input with the cursor balanced, behind the `CursorBackend` trait) are portable and tested on Linux, with `proptest` for the invariants. `sys` (macOS only) has the tap, its thread with CFRunLoop, the real cursor (CoreGraphics), Secure Event Input (Carbon) and the permissions (`AXIsProcessTrusted*`, `CGPreflight/RequestListenEventAccess`).
- `MacCapture::start(sink)` delivers each event to `sink` on the tap's thread; `sink` returns `false` if nobody is listening anymore, and then the capture gives the input back by itself. `set_grab(bool)` and `warp(Point)` have the same signature as T-026's `Capture` trait (PR #14, not yet merged): once both are in `develop`, `impl Capture for MacCapture` is a direct delegation.
- With local focus, `MotionRelative` (the `kCGMouseEventDeltaX/Y`, with macOS acceleration) comes out followed by `MotionAbsolute` with the real position: the server adds the delta to the previous position, so at the edge (where macOS already pinned the cursor) the push crosses. With remote focus, deltas only.
- Modifiers per side with the `NX_DEVICE*KEYMASK` bits of `CGEventFlags`; Caps Lock comes out as a full keypress on each `FlagsChanged`; Fn does not travel (it has no standard HID usage).
- Scroll: wheel in v120 (`FixedPtDeltaAxis*` × 120), trackpad in pixels (`PointDeltaAxis*`); "natural scrolling" is undone by reading `com.apple.swipescrolldirection` (re-read on every crossing).
- Media keys (`NSSystemDefined` subtype 8) → HID consumer page; they are read with `NSEvent`.
- Events with `kCGEventSourceUserData == INJECTED_MARKER` ("TNDM") pass through without being forwarded: T-023 should mark what it injects this way.
- Hiding the cursor without being the active app uses the private API `CGSSetConnectionProperty(..., "SetsCursorInBackground")` (DESIGN and research). `objc2-app-kit` is now declared without default features in the workspace; each crate enables the classes it uses.
