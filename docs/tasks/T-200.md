# T-200 — Everything in the repository in English

## Context

The user wants the whole repository in English: UI, code, identifiers, file names, comments, tests, docs, tasks, reports, commits, PRs and CI job names. Only the conversation with the user stays in Spanish. This task changes the rule (`CLAUDE.md`, `.claude/agents`, `.claude/rules`), adds `docs/GLOSSARY.md` and splits the migration into tasks that own disjoint directories, so they can run in parallel without conflicts.

## Plan

| Task | Owns | Order |
|---|---|---|
| T-201 | Visible UI text + mockups + mockup PNGs + versioned screenshots + `tools/mockup-render` + `mockups/README.md` (one PR: parity depends on both sides) | first wave |
| T-202 | UI code: file names, identifiers, comments, test names and test files in `apps/tandem-ui/src` and `apps/tandem-ui/scripts` | after T-201 |

| T-207 | `docs/tasks/` (except T-200…T-208), `docs/reports/` (text and folder names), `docs/STATUS.md`, `scripts/ci/tareas.sh` and `status.sh` (they parse task headings) | first wave |
| T-208 | `scripts/` (rest), `.github/workflows/` (job names), `.claude/workflows/`, `tools/` (except `mockup-render`), hook messages | after T-207 |

Shared rules for every migration task:

- Translate, do not rewrite: same meaning, same structure, no features removed or added.
- Use `docs/GLOSSARY.md`. Do not edit the glossary; list new terms you chose in the PR description.
- Rename files with `git mv` and update every reference in the same PR.
- At the end, `git grep -nP '[áéíóúñ¿¡]'` over your directories must be empty, and a word check for common Spanish words (`\b(el|la|los|las|de|que|con|para|una|sin|por)\b` in strings and comments) must come back clean or with justified exceptions listed in the PR.
- Quality gate and CI green; parity (`pnpm shots --check`) where it applies.
