# T-117 — Arrangement screen (4 sides) and crossing test

## Context

DESIGN §12. Reference mockups (visual and interactive source of truth): `V3-Arrangement` (states: the other machine on each of the 4 sides × 3 alignments; each screen selected), `F-CrossingTest`. The screen must look and behave the same as the mockup: same structure, sizes, colors, icons, texts, animations and transitions; everything interactive in the mockup really works against the agent.

## Scope

1. Canvas with the screens at real physical scale, centered automatically; the chosen screen is highlighted; the green vertical or horizontal crossing edge follows the arrangement with animation.
2. Panel: thumbnail + name + machine, read-only data with icons (size, resolution, aspect ratio, scale), **mini plan with 4 slots** to place the other machine (top, bottom, left, right) with the tile that slides, segmented alignment that changes from Top/Center/Bottom to Left/Center/Right depending on the side. No X/Y.
3. Incompatible or disconnected screens: "Not compatible: it does not fit in the arrangement".
4. Save → shared config (T-099). "Test crossing" (`F-CrossingTest`): asks to cross through the arrangement's edge and passes with the crossing the agent reports. The UI and demo mode are here; having the real agent report the crossing (`CursorSample`) belongs to T-128 (`docs/tasks/T-128.md`).

## Acceptance criteria

- [x] Similarity ≥ 0.99 against each listed mockup and state, in the screenshot harness (T-112/T-125), with the screenshots saved in `docs/screenshots/v03/`.
- [x] Everything that is interactive in the mockup works connected to the agent (real IPC: "Save" → `set_arrangement`) and in demo mode; vitest tests of the logic and of the interactions. The crossing test with the agent's real cursor is not part of this task: T-128 does it.
- [x] Mockup animations and transitions present; with `prefers-reduced-motion` they are turned off (test).
- [x] No filler texts or elements without a function (DESIGN §3.8).
- [x] `pnpm test`, `pnpm build`, `pnpm check` and CI green.
