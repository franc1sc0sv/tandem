# T-123 — Nightly hardware suite

## Context

DECISIONS A8. The user authorized real unattended tests, with mandatory automatic rollback on monitors.

## Scope

1. `scripts/hw/` with an orchestrator (bash from WSL) that: builds the Windows and macOS binaries (on the Mac over ssh, `cargo build --release` in a checkout of `develop`), installs and starts the two agents with test configs (data in temporary folders, without touching the user's installation), pairs them with preprovisioned identities and runs tests:
   - link over Wi-Fi: control and input latency (T-093);
   - tunnels: open from PC to Mac and from Mac to PC, processes, files, ports, git workspace (T-103…T-108);
   - monitors (once T-110 exists): probing of the 34" and input switch **with automatic rollback** by the watchdog;
   - synthetic input: inject movement on one machine and check the crossing on the other (without depending on moving the physical mouse).
2. Report in `docs/reports/hw-<date>.md` with results and trimmed logs.
3. It never leaves test processes alive nor changes the user's real configuration; cleanup at the end even if something fails (`trap`).
