## Notes

**Cause:** `tandemd::drag::serve` registered the destination's request channel inside its spawned task, and `DragHub::deliver` threw away any `Begin`/`Ready`/`Cancel` that arrived before that. The tests spawn `serve` from the test's main thread, which puts it on tokio's injection queue, and start `run_origin` right away. On a busy runner the workers keep polling the network tasks first (local queue and LIFO slot), so they can deliver the `Begin` before the `serve` task has run at all. The source then waits for `Staged` forever. That is the 20 s `within` in both failures (Ubuntu `canceling_midway...`, macOS `the_drag_copies...`). The daemon has the same race, because it spawns `serve` after starting the network. This is not a link-timing problem, which is why T-195 could not fix it.

**Fix:** `DragHub` holds requests that arrive before anyone serves in a bounded queue (`EARLY_REQUESTS = 8`, oldest dropped first). When `serve` registers, it takes them over in order. Replies with no drag waiting are still discarded.

**Forcing test:** `drag.rs::a_begin_that_arrives_before_the_destination_serves_is_not_lost` starts the origin, waits 500 ms and only then spawns `serve`. It timed out before the fix and passes after it. Unit tests in `src/drag.rs` cover the order, the bound and the replies.

**Labels:** every `within` in `crates/tandemd/tests` is now `#[track_caller]`, and its panic says `waiting at <file>:<line>` (the pattern `input.rs` already used). `within_for` in `pairing.rs` keeps its text labels.

**Temporary directories:** `workspace.rs` (T-197) created its temp dir with `tempdir_in(".")`, so a killed or aborted run left `crates/tandemd/.tmp*` behind. The dir now lives in `CARGO_TARGET_TMPDIR` and is named relative to the cwd (`../..`). The helper that builds that path has its own test.

**Evidence:** the forcing test fails before the fix. After it: 0/60 runs of `drag` under load (8 `yes`, `taskset -c 0,1`), `cargo test --workspace` green, and run 44442801041 (a temporary workflow, since removed) ran all `tandemd` integration tests 20 times on each of Ubuntu, Windows and macOS with 0 failures. T-190 is superseded (see its notes). T-235 is closed in this branch.
