# T-222 — Spanish field names in the agent log

Found by the acceptance agent (part B, round 3, `docs/reports/acceptance-2026-11-18-b3.md`), rule G9 ("no Spanish anywhere in the app"). The English migration (T-200 to T-209) and the T-205 accent grep do not catch it: the words have no accents.

## What fails

Reading the agent logs of the real agents (`<data dir>/logs`, the file that Settings > Advanced > "Agent logs" opens) two structured fields are Spanish:

- `crates/tandemd/src/daemon.rs` line 74: the field that carries the machine's public key in `this machine's identity` (the Spanish word for "key").
- `crates/tandemd/src/agent/env.rs` line 132: the field that carries the number of environments in `environments scanned` (the Spanish word for "environments").

Every other line of the log (about 60 distinct messages in a full run) is English.

## Expected fix

- Rename both fields (`key`, `environments`) and anything that parses them (tests, harness, docs).
- The T-210 CI guard already lists these words; make sure it covers `.rs` identifiers inside `tracing::` macros so it would have caught this.

## Acceptance criteria

- [ ] No Spanish word in any tracing field or message (checked by running two agents and reading both logs).
- [ ] Quality gate and CI green.
