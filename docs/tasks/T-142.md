# T-142 — Remove "Add machine" from the "First time" card

## Context

Finding of the acceptance agent (part A), rule G1/D1. D1 says "there is no third machine nor 'add machine'; the other one can be changed" and `mockups/README.md` covers or replaces that text in the sidebar, Desk, Settings and Palette. The "Single-machine desk" card of `#/states` (`apps/tandem-ui/src/lib/states.ts`) keeps the mockup's text: "…appears off with 'Add another machine to use this'" and the "Add machine" button (opens pairing, `does: "add-machine"`). Screenshot: `docs/reports/acceptance/2026-11-18-a/states-add-machine/app.png`.

## Scope

1. Change the text and the button to D1's vocabulary ("Pair the other machine", without "add"), with the same icon and the same action (setup at the pairing step).
2. Add the allowed difference to `mockups/README.md` (with its reason, D1) and cover only the label of that button and the card's sentence in `shots-spec.ts` (`states`), without covering the whole card.
3. Check that no other visible string says "add machine" / "other machine" in the sense of adding a third one (search in `src/` excluding tests).
