# T-345 — Stale pairing after a reinstall

Found on real hardware on 2026-11-19.

## What happens

- The PC was uninstalled without ticking "Delete application data", then v0.3.0 was installed. `%APPDATA%\Tandem\trust.toml` still trusted the old Mac key. The Mac had been reset and had a new identity.
- The PC's UI showed "machine A is off" on Desk, an empty Network diagram, and **no way to pair** with the new Mac, which was announcing itself for pairing on the same LAN. The user only got out of it by renaming the data folder by hand.

## Scope

1. When the paired peer has not been seen for a while and another Tandem machine is announcing itself for pairing on the LAN, Desk shows "<name> is not answering. Another Tandem machine is looking for a pair" with an action to forget the old pair and pair with the new one (with confirmation).
2. Settings always has "Forget this pair and pair again", even when the other machine is off.
3. The uninstaller's "Delete application data" box text says that keeping data keeps the pairing.

## Acceptance criteria

- [x] Agent test: with a stale trusted peer and a pairing announcement from an unknown key, the agent reports "pairing offer from another machine" over IPC.
- [x] UI tests (vitest) for the Desk notice and the Settings action; screenshot of the notice.
- [x] Forgetting and pairing again works in a two-agent test where one side kept its old trust file.
- [x] Quality gate and CI green.

## Notes

- Agent: `PairingStatus::Offered` (protocol v43), published by `crates/tandemd/src/offer.rs` while the paired peer has had no link for `NetOptions::stale_after` (20 s by default) and `MdnsDiscovery::pairing_offers` sees a `_tandem-pair._udp` announcement whose key is not the peer's. Tests: `offer.rs` (state machine with paused time), `tests/pairing.rs` (`a_stale_peer_and_a_pairing_announcement_is_reported_as_an_offer`, `forgetting_a_stale_pair_and_pairing_again_works`, with the LAN's announcements fed by the test because CI has no multicast) and the resolver test in `tandem-link`.
- UI: Desk shows the notice (`desk-offer` screenshot, recorded without a threshold: the mockup has no such state); Settings → Desk and machines has the row "Forget this pair and pair again", last in the list so the F-Settings comparison keeps its row alignment (the row is masked).
- Uninstaller: the box text comes from `windows/English.nsh` and `windows/Spanish.nsh`, copies of the Tauri 2.10.3 bundler's files (the version `@tauri-apps/cli` 2.12.3 pins) with `deleteAppData` changed. The installer job in CI builds and tests it.
