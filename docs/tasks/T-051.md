# T-051 — Acceso SSH a la Mac para pruebas

## Alcance

El usuario activa Sesión remota en la Mac y autoriza la llave de WSL; se crea el host `mac-runner` en `~/.ssh/config`; se documenta en docs/dev/hardware.md cómo el agente hardware-verifier compila y corre pruebas allí.

## Criterios de aceptación

- [ ] `ssh mac-runner uname -a` funciona desde WSL.
