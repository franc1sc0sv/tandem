# T-357 — `tandem` in the app bundle and the Windows installer

## Context

On 2026-11-24 the user's Claude could not use the `tandem` MCP on either machine: on the Mac, MCP ran
a `tandem` installed apart with `cargo install` (0.3.2, protocol 47), which the 0.3.3 agent refused;
on the PC there was no `tandem` at all, because the installer only ships `tandemd` and `tandemw`.

## Scope

- `scripts/macos/bundle.sh` builds `tandem-cli` with `tandemd` and the app carries it as a sidecar
  (`tauri.sidecar.json`): `Tandem.app/Contents/MacOS/tandem`.
- The Windows installer builds and ships `tandem.exe` (`installer.conf.json`, `build-installer.ps1`),
  checked by `test-installer.ps1`.
- DESIGN §13.

## Acceptance criteria

- [x] Both bundles list `binaries/tandem`; the bundle and installer scripts build and check it.

## Pending hardware verification

- [ ] After updating, `Tandem.app/Contents/MacOS/tandem --version` and `%LOCALAPPDATA%\Tandem\tandem.exe --version` print the app's version, and Claude's MCP (pointed at them) connects.
