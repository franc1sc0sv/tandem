# T-211 — `docs/examples/*.toml` still entirely in Spanish

## Context

Finding of the acceptance agent (part A, round 3), rule G9 ("no Spanish anywhere") and the English-only rule (T-200). The four example configuration files are what a user copies to write a `tandem.toml`, and every comment in them is Spanish:

- `docs/examples/tandem.mac.toml` (128 lines)
- `docs/examples/tandem.pc.toml` (94 lines)
- `docs/examples/v0.2/tandem.mac.toml` (106 lines)
- `docs/examples/v0.2/tandem.pc.toml` (85 lines)

None of the T-201…T-208 migration tasks owned `docs/examples/` (T-206 covered `docs/*.md`, `docs/dev` and `docs/research`), so it was never translated. A search for accented Spanish characters finds dozens of lines there.

## Expected fix

1. Translate the comments of the four files with `docs/GLOSSARY.md` (desk, machine, scene, pairing, rollback…). Do not change keys, values or structure.
2. Keep the examples loading: the existing config tests that read `docs/examples/*.toml` (if any) and `tandemd --check-config` over the four files must still pass.

## Acceptance criteria

- [x] No accented Spanish characters or common Spanish words are left in the comments of `docs/examples`.
- [x] `tandemd --check-config` accepts the four files as before.
- [x] Quality gate and CI green.
