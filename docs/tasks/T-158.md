# T-158 — The modules say that functions that already work do not exist

Found by the acceptance agent (part B), flows F11 and F1 (verified summary).

## What fails

`crates/tandemd/src/modules.rs` declares `Tunnels` and `Files` always `Unavailable { reason: NOT_YET }` ("Not in this version of Tandem yet"). With two real agents the tunnels work end to end (F5: processes, files, ports, `bring_back`), and file drag has its module (T-121), but:

- The machine page (Modules) shows "Tunnels: Not in this version of Tandem yet — unavailable" and the same for Files.
- Setup step 1: "Compute — Not in this version of Tandem yet"; and the final summary (step 6, "This was really verified") says "Remote compute: remote compute is missing on one of them" with tunnels working.
- `docs/ACCEPTANCE.md` F11: "correct 'unavailable' reasons".

## Screenshots

- App: `docs/reports/acceptance/2026-11-18-b/F11-modules/01-machine-page.png` and `F1-setup/06-compute-summary.png`.
- Mockup: `mockups/v03/V3-Machine.dc.html`, `F-Setup6.dc.html`.

## Expected fix

- `Tunnels::state` is `Active`/`Off` according to the module being on and `Unavailable { reason }` only with a true reason (for example, no execution environment detected); `Files` according to whether or not there is a drag backend on the system.
- The setup summary reads that state.
- Module tests with and without a backend; a test that no reason says "not yet" if the function exists.

## Acceptance criteria

- [x] The "unavailable" reasons describe something true on each system.
- [x] The setup summary reflects that the tunnels work.
- [x] Quality gate and CI green.

## Notes

Fixed on the `fix/aceptacion-b-ui` branch; the tests are in `apps/tandem-ui/src/screens/aceptacion-b.test.ts` and `modules.rs` (Tunnels and Files active; Files reports `NO_FILE_DRAG` if the system does not open the detector).

Files reasons: `NO_FILE_DRAG` (the system did not open the detector), `NO_FILE_DRAG_OS` (unsupported system, e.g. Linux) and `NO_ENGINE` (the engine did not start). Test through the real path: `files_module_follows_the_drag_backend` in `crates/tandemd/tests/input.rs`.
