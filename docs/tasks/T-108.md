# T-108 — MCP and CLI

## Context

DECISIONS D8; DESIGN §8; mockup `F-ClaudeMCP`.

## Scope

1. `tandem mcp`: MCP server over stdio (`rmcp` crate or another maintained one; otherwise, a minimal implementation of the protocol with tests). Tools: `machines`, `resources`, `tunnels`, `tunnel_open`, `tunnel_close`, `exec`, `output`, `kill`, `files_put`, `files_get`, `port_forward`, `bring_back`. Clear descriptions in Spanish and English so Claude chooses well.
2. `tandem` (CLI) with the same subcommands and readable output + `--json`.
3. Tunnel title: the one the client (the Claude session) passes or the project name.
4. `docs/dev/mcp.md`: how to add it (`claude mcp add tandem -- tandem mcp`) and examples.
5. The wizard (step 6) shows that command with a copy button.

## Notes

- `tandem-cli` crate (`tandem` binary): `spec` (single table of tools: parameters, JSON schema and es/en descriptions), `api::Api` (the only place that translates tool to `UiCommand`; checks arguments), `mcp` (line-based JSON-RPC 2.0, `initialize`/`ping`/`tools/list`/`tools/call`, by hand), `cli` (flags generated from the table, `--json`, `--data-dir`) and `render` (readable text).
