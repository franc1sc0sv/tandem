# T-108 — MCP y CLI

## Contexto

DECISIONS D8; DESIGN §8; mockup `F-ClaudeMCP`.

## Alcance

1. `tandem mcp`: servidor MCP por stdio (crate `rmcp` u otro mantenido; si no, implementación mínima del protocolo con pruebas). Herramientas: `machines`, `resources`, `tunnels`, `tunnel_open`, `tunnel_close`, `exec`, `output`, `kill`, `files_put`, `files_get`, `port_forward`, `bring_back`. Descripciones claras en español e inglés para que Claude elija bien.
2. `tandem` (CLI) con los mismos subcomandos y salida legible + `--json`.
3. Título del túnel: el que pase el cliente (la sesión de Claude) o el nombre del proyecto.
4. `docs/dev/mcp.md`: cómo agregarlo (`claude mcp add tandem -- tandem mcp`) y ejemplos.
5. El asistente (paso 6) muestra ese comando con botón de copiar.

## Criterios de aceptación

- [ ] Prueba de integración: un cliente MCP de prueba abre túnel contra un agente con el doble, ejecuta, lee salida, copia un archivo, abre un puerto y cierra.
- [ ] Pruebas de la CLI (salida `--json` estable).
- [ ] Puerta de calidad y CI en verde.

## Verificación en hardware pendiente

- [ ] Desde una sesión real de Claude Code en WSL: «corre los tests de este repo en la Mac» funciona de punta a punta por Wi-Fi.
