# T-010 — DDC/CI en Windows (dxva2) + CLI tandem-ddc

## Alcance

`tandem-display::windows::ddc`: enumerar monitores físicos (EnumDisplayMonitors + GetPhysicalMonitorsFromHMONITOR), modelo por EDID (WmiMonitorID o SetupAPI), leer capabilities string, leer/escribir VCP. Todo bajo `cfg(windows)`.
Binario `tandem-ddc` (en el crate): `list`, `caps <monitor>`, `get <monitor> <vcp>`, `set <monitor> <vcp> <valor>`, `switch <monitor> hdmi|dp --return-after <s>` (siempre con vuelta automática; ver docs/research/ddc-34-LC34G55T.md).

## Criterios de aceptación

- [x] Compila para `x86_64-pc-windows-gnu` y en CI windows.
- [x] Parser del capabilities string con pruebas (usar el string real del LC34G55T de docs/research).
- [x] La verificación en el monitor real la hace T-050, no esta tarea.

## Notas

- Lógica portable en `tandem-display::ddc` (trait `DdcBus`, parser de capabilities, EDID, cambio con vuelta) y `tandem-display::cli`; se prueba en Linux con `ddc::fake::FakeDdc`. El backend real es `tandem-display::windows::ddc::WindowsDdc`.
- El modelo sale del EDID del registro (`HKLM\SYSTEM\CurrentControlSet\Enum\DISPLAY\...\Device Parameters\EDID`), encontrado con la ruta de interfaz de `EnumDisplayDevicesW`; no hace falta WMI ni SetupAPI.
- `switch` siempre vuelve: la vuelta se manda aunque la ida falle, con 3 reintentos por código; Ctrl+C la adelanta y al cerrar la consola el manejador espera a que se mande. `--return-after` es obligatorio (1–300 s). La vuelta va por omisión a la otra entrada y no puede ser la misma de la ida (error de uso, sin escribir nada).
- Perfil incluido para el 34" (`LC34G55T` en el nombre del EDID): HDMI `0x06`, vuelta a DP con `0x0F` y luego `0x09` (hasta aislar cuál basta, T-050). Otros monitores usan MCCS estándar o `--code`/`--return-code`.
- `set` rechaza `0x60` y `0xD6` porque no traen vuelta automática.

## Verificación en hardware pendiente

- [ ] `tandem-ddc list` enumera los dos monitores y muestra modelo/serie del EDID (comprobar que el nombre del 34" contiene `LC34G55T`; si no, ajustar `known_profile`).
- [ ] `tandem-ddc caps 0` devuelve el string de docs/research y se interpreta sin error.
- [ ] `tandem-ddc switch <34"> hdmi --return-after 10` cambia a la Mac y vuelve a DP solo (lo hace T-050 con el usuario mirando).
- [ ] Ctrl+C durante la espera adelanta la vuelta; cerrar la ventana de la consola también la manda.
