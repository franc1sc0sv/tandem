# T-012 — Display control on macOS

## Scope

`tandem-display::macos`: list displays (CGGetOnlineDisplayList + model), deactivate/activate (CGSConfigureDisplayEnabled, private), mirroring (CGConfigureDisplayMirrorOfDisplay), applied to external monitors and to the built-in display (DESIGN §8.1). Spike S2 documented in docs/research/.

## Acceptance criteria

- [x] Compiles on macos CI.
- [x] S2 research note (`docs/research/macos-displays-s2.md`).

## Notes

- Portable logic in `tandem_display::quartz` (`MacTopology` over the `QuartzApi` trait, `FakeQuartz` double); real backend in `tandem_display::macos` (`CgApi`, direct FFI to CoreGraphics, private ones via `dlsym`).
- `MacTopology::{attach, detach, set_builtin, restore_all}` receive the `tandem-core` types (`MonitorConfig`, `BuiltinDisplay`) so that T-014 can connect them to the executor.
