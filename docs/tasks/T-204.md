# T-204 — Link, input, environment, simulation, hardware and monitor crates in English

## Context

See T-200.

## Scope

`crates/tandem-link`, `tandem-input`, `tandem-env`, `tandem-sim`, `tandem-hw`, `tandem-monitor` and the DDC crates: comments, doc comments, test names, error and log messages. `// SAFETY:` comments stay, translated.

## Acceptance criteria

- [x] No Spanish in these crates (left on purpose: Spanish-keyboard key labels, a Spanish-localized `wsl` header and strings produced by `tandem-proto`/`tandemd`, see Notes).
- [x] Quality gate and CI green; `scripts/ci/safety.sh` still passes.

## Notes

Spanish kept on purpose:

- `tandem-input/src/event/keymap.rs`: the `ISO_ES` test table is the label set of a real Spanish ISO keyboard (`Ñ`, `¡ ¿`, `Mayús izq.`, `BloqMayús`, `Menú`, `RePág`, `AvPág`, `Retroceso`, `Intro`, `Supr`, and so on). It is data.
- `tandem-env/src/parse.rs`: the `wsl -l -v` header test uses a Spanish-localized header (`NOMBRE ESTADO VERSIÓN`).
- `tandem-hw/src/report.rs` and `tandem-input/examples/mac_emulate.rs`: `ñ` names the key being tested.
- `tandem-link/{discovery/fingerprint,identity/public_key}.rs`: `"é"` is a non-ASCII input that must be rejected.
- `tandem-link/src/iface/assign.rs`: the Spanish `netsh` words (`elevación`, `administrador`, `acceso denegado`, `requiere`) are matched against the output of a Spanish Windows.
- Texts produced by other crates and asserted by tests here (`tandem-link/tests/transport.rs`, `tandem-sim/tests/{monitors,scene_monitors}.rs`) and the default scene names ("Trabajo", "Solo A", ids `trabajo`, `solo-a`) stay until `tandem-proto` and `tandemd` are translated.
