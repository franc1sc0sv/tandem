# T-023 — Input injection on macOS

## Scope

`tandem-input::macos::emulate`: keyboard with flags, repeat, mouse with Dragged events and click state, pixel scroll, media keys.

## Acceptance criteria

- [x] Compiles on macos CI. (On WSL, `cargo clippy -p tandem-input --all-targets --target aarch64-apple-darwin -- -D warnings` also passes.)
- [x] Manual test documented (below and in `crates/tandem-input/examples/mac_emulate.rs`).

## Notes

- `MacEmulator<S: MacSink>` translates `InputEvent` into `MacEvent` (portable, tested on Linux with `RecordingSink`); `CgSink` (macOS only) publishes them with `CGEventPost(kCGHIDEventTap)` and the media keys with `NSEvent` `SystemDefined` subtype 8.
- Modifiers as `kCGEventFlagsChanged`, with the side bits (`NX_DEVICE*`) to distinguish right Option/Cmd/Shift/Ctrl. Caps Lock toggles `AlphaShift` on press.
- Repeat: a key pressed again without being released goes out with `kCGKeyboardEventAutorepeat`; modifiers do not repeat.
- Arrows with `NumericPad|SecondaryFn`, F/Home/End/PgUp/PgDn/Delete with `SecondaryFn`, numeric keypad with `NumericPad`.
- Mouse: `*Dragged` of the lowest pressed button; `kCGMouseEventClickState` with the Mac's double-click window (`NSEvent.doubleClickInterval`) and 4 pt tolerance; the cursor is clamped to the nearest active display.
- Scroll: the wheel in lines (accumulating v120 fractions), the trackpad in pixels (accumulating fractions); the sign follows `com.apple.swipescrolldirection` (without the key, natural scrolling on, as it ships from the factory).
- The keyboard-page volume (0x7F–0x81) also goes out as a system key: as a keycode macOS ignores it.
- `release_all()` releases one by one, in the order of `Pressed::release_all`, so that each event carries the modifiers that are still down.
- `CgSink` uses a `HIDSystemState` source with suppression interval 0, so that the Mac's local trackpad keeps responding while injecting.
- The workspace's `objc2-*` dependencies stay with `default-features = false` (otherwise they pull in every framework); each crate enables `std` and whatever it uses.
- T-026's `Injector` is implemented on top of `MacEmulator::emit` once that task is in `develop`.

## Manual test

On the Mac, with Accessibility granted to the terminal and an empty text editor in the foreground:

```
cargo test -p tandem-input --lib macos::emulate::cg -- --ignored --nocapture
cargo run -p tandem-input --example mac_emulate
```

The example, after 3 s: types «tandem», Shift + the Spanish-layout n-tilde key (HID 0x33) and left arrow; holds "a" for 10 repeats; draws a 200 px square with the cursor; double-clicks (selects a word); scrolls three notches backward, three forward and then in pixels; raises and lowers the volume.
