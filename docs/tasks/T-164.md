# T-164 — Criterios sin marcar y encabezados de hardware en tareas hechas

## Context

Falla encontrada por el agente de aceptación, parte C (2026-11-18, `origin/develop` 04f2967). Ver `docs/reports/acceptance-2026-11-18-c.md`.

## Failure

Tareas `done` con criterios sin marcar o con la lista de hardware fuera del protocolo:

- `T-051`: «`ssh mac-runner uname -a` funciona desde WSL» sin marcar, aunque la nota del 2026-11-16 dice que funciona.
- `T-115`: «`pnpm test`, `pnpm build`, `pnpm check` y CI en verde» sin marcar (en esta corrida los tres pasan y el PR se integró con CI verde).
