# T-007 — tandemd: esqueleto del agente

## Alcance

Binario `tandemd`: runtime tokio, logging con tracing (archivo + stdout), carga de `tandem.toml` (config de `tandem_core::Config` + red + máquina local), persistencia de `State` en JSON en el directorio de datos de la app, apagado ordenado.
IPC local para la UI: Unix socket en macOS / named pipe en Windows, accesible solo al usuario actual, hablando los mensajes UI↔agente de tandem-proto.

## Criterios de aceptación

- [x] `tandemd --check-config <archivo>` valida una config y sale con código ≠ 0 si es inválida.
- [x] Prueba: el estado se guarda y se recarga igual.
- [x] Prueba de integración: un cliente IPC pide el estado y lo recibe (en Linux con Unix socket).

## Notas

- `tandem.toml` = `machine` + `[network]` (`port`, por omisión 47770; `peers` opcionales) + los `[[monitors]]` de `tandem_core::Config`. Lo leen `--check-config` y el arranque.
- Rutas por omisión: `dirs::data_dir()/Tandem` (estado `state.json`, `logs/tandemd.log`, socket `tandemd.sock`) y `dirs::config_dir()/Tandem/tandem.toml`; `--config` y `--data-dir` las cambian. El nivel de log sale de `TANDEM_LOG`.
- El estado guardado se ajusta a la config al arrancar (monitores nuevos en la Mac, los que ya no están se olvidan); un `state.json` dañado se aparta como `state.json.corrupt` y se parte del estado inicial.
- IPC: el agente saluda primero, la UI contesta con su `Hello` y luego pide con `UiRequest`; los cambios de estado se empujan como `AgentToUi::State`. `SetMode`, `MoveMonitor` y `SetBuiltin` responden `Rejected("todavía no implementado")` hasta el orquestador (T-008).
- Solo el usuario actual: en Unix, directorio 0700, socket 0600 y comprobación del uid del cliente (`peer_cred`); en Windows, pipe `\\.\pipe\tandemd-<SID>` con DACL protegida que solo admite el SID del proceso y sin clientes remotos. El caso del servicio SYSTEM con la UI en la sesión del usuario queda para T-027.
- Un segundo `tandemd` sobre el mismo socket o pipe sale con error; un socket viejo de un agente muerto se reemplaza.
