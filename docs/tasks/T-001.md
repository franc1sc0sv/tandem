# T-001 — Esqueleto del workspace con todos los crates

## Alcance

Crear (vacíos pero compilando) todos los crates de DESIGN §4.2 para que las tareas siguientes no choquen en `Cargo.toml`/`Cargo.lock`:
`tandem-proto`, `tandem-link`, `tandem-display`, `tandem-input`, `tandem-clipboard`, `tandem-peripherals`, `tandem-power` (libs) y `tandemd` (bin).
Declarar en `[workspace.dependencies]` las dependencias previstas con versión fijada: tokio, tracing, tracing-subscriber, anyhow, quinn, rustls, rcgen, ed25519-dalek, postcard, serde, windows, objc2 / objc2-core-graphics / objc2-app-kit / objc2-foundation, keycode, arboard, mdns-sd. Solo declararlas; cada crate usa lo suyo cuando lo necesite.
Las dependencias de plataforma van bajo `[target.'cfg(windows)'.dependencies]` y `[target.'cfg(target_os = "macos")'.dependencies]`.

## Criterios de aceptación

- [ ] `cargo build --workspace`, `cargo clippy --workspace --all-targets -- -D warnings` y `cargo test --workspace` pasan en Linux.
- [ ] `cargo check --workspace --target x86_64-pc-windows-gnu` pasa.
- [ ] Cada crate tiene un `lib.rs` con un doc-comment que dice su responsabilidad (copiado de DESIGN §4.2).
- [ ] CI verde en ubuntu, windows y macos.
