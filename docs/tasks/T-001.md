# T-001 — Esqueleto del workspace con todos los crates

## Alcance

Crear (vacíos pero compilando) todos los crates de DESIGN §4.2 para que las tareas siguientes no choquen en `Cargo.toml`/`Cargo.lock`:
`tandem-proto`, `tandem-link`, `tandem-display`, `tandem-input`, `tandem-clipboard`, `tandem-peripherals`, `tandem-power` (libs) y `tandemd` (bin).
Declarar en `[workspace.dependencies]` las dependencias previstas con versión fijada: tokio, tracing, tracing-subscriber, anyhow, quinn, rustls, rcgen, ed25519-dalek, postcard, serde, windows, objc2 / objc2-core-graphics / objc2-app-kit / objc2-foundation, keycode, arboard, mdns-sd. Solo declararlas; cada crate usa lo suyo cuando lo necesite.
Las dependencias de plataforma van bajo `[target.'cfg(windows)'.dependencies]` y `[target.'cfg(target_os = "macos")'.dependencies]`.

## Criterios de aceptación

- [x] `cargo build --workspace`, `cargo clippy --workspace --all-targets -- -D warnings` y `cargo test --workspace` pasan en Linux.
- [x] `cargo check --workspace --target x86_64-pc-windows-gnu` pasa.
- [x] Cada crate tiene un `lib.rs` con un doc-comment que dice su responsabilidad (copiado de DESIGN §4.2).
- [ ] CI verde en ubuntu, windows y macos.

## Notas

- `tandemd` tiene `main.rs` y además un `lib.rs` con el doc-comment, para cumplir el criterio y poder probar su lógica sin arrancar el servicio.
- Las dependencias de `[workspace.dependencies]` se verificaron aparte: resuelven juntas, las portables compilan en Linux y `windows` compila para `x86_64-pc-windows-gnu`. `rustls` queda en 0.23 (la que usa quinn 0.11; 0.24 es prerelease).
- Para el cross-check a Windows de crates que usen `quinn`/`rustls` (ring/aws-lc-sys) hará falta `x86_64-w64-mingw32-gcc` en WSL; hoy no está instalado.
