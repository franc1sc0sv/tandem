# T-001 — Workspace skeleton with all crates

## Scope

Create (empty but compiling) all the crates from DESIGN §4.2 so later tasks do not clash in `Cargo.toml`/`Cargo.lock`:
`tandem-proto`, `tandem-link`, `tandem-display`, `tandem-input`, `tandem-clipboard`, `tandem-peripherals`, `tandem-power` (libs) and `tandemd` (bin).
Declare the planned dependencies in `[workspace.dependencies]` with pinned versions: tokio, tracing, tracing-subscriber, anyhow, quinn, rustls, rcgen, ed25519-dalek, postcard, serde, windows, objc2 / objc2-core-graphics / objc2-app-kit / objc2-foundation, keycode, arboard, mdns-sd. Only declare them; each crate uses what it needs when it needs it.
Platform dependencies go under `[target.'cfg(windows)'.dependencies]` and `[target.'cfg(target_os = "macos")'.dependencies]`.

## Acceptance criteria

- [x] `cargo build --workspace`, `cargo clippy --workspace --all-targets -- -D warnings` and `cargo test --workspace` pass on Linux.
- [x] `cargo check --workspace --target x86_64-pc-windows-gnu` passes.
- [x] Each crate has a `lib.rs` with a doc comment stating its responsibility (copied from DESIGN §4.2).
- [x] CI green on ubuntu, windows and macos.

## Notes

- `tandemd` has a `main.rs` and also a `lib.rs` with the doc comment, to meet the criterion and to be able to test its logic without starting the service.
- The `[workspace.dependencies]` dependencies were verified separately: they resolve together, the portable ones compile on Linux and `windows` compiles for `x86_64-pc-windows-gnu`. `rustls` stays at 0.23 (the one quinn 0.11 uses; 0.24 is a prerelease).
- For the Windows cross-check of crates that use `quinn`/`rustls` (ring/aws-lc-sys), `x86_64-w64-mingw32-gcc` will be needed in WSL; it is not installed today.
