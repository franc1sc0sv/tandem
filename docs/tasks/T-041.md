# T-041 — UI: main scene

## Scope

Port the mockup's scene: machines, draggable monitors, links, mode cards, power button, keyboard/mouse chip, built-in display control, services locked without a cable, step-by-step transaction progress. Connected to the real IPC.

## Acceptance criteria

- [x] Visually equivalent to `mockups/main.html` (screenshot in the PR).
- [x] Keyboard accessible (shortcuts ⌃⌥1/2/3).

## Notes

- **Live session with tandemd** (`tandem_ui::session`): one connection open over the IPC that asks for the desk and the state on connecting and forwards to the window what the agent pushes. Tauri events `agent-snapshot` (everything needed to draw) and `agent-notice` (transaction progress and manual-switch requests); commands `agent_snapshot`, `agent_act` and `agent_retry`. If there is no agent, the window shows the reason and the session retries every 2 s (or when «Retry» is pressed). Tested with a real `tandemd` over the in-memory IPC. T-040's polling every 3 s is removed.
- **Extended IPC** (protocol version 1 → 2): `UiCommand::GetDesk` → `Reply::Desk(Config)` to draw the monitors with their name and their wiring, and `UiCommand::SetPcPower(bool)` for the power button (power on = `PowerOnPc`; power off = `Plan::shutdown_pc`, which returns everything to the Mac first).
- **Scene** ported from the mockup: draggable monitors (and with Enter/Space from the keyboard), mode cards as buttons with ⌃⌥1/2/3 (by `KeyboardEvent.code`, because on macOS ⌥ changes the key), power button with state (off, starting, on), built-in display selector with the automatic rule, step-by-step transaction progress (each monitor's steps are grouped into one), rollback or uncertain-state notice, and manual input-switch request with «Done» / «Can't».
- **What the IPC does not yet report is shown without data, not invented**: link status (dotted rails and «link: no data»; services stay locked with «requires cable»), where the hub is and who is the keyboard and mouse server («no data» chip), and «Bring windows» (disabled). They need to be exposed in the IPC in their own tasks.
- The built-in display in «mirror» or «extended» is requested with `SetBuiltin`, which the agent still rejects as not implemented: the window shows the rejection.
- Default window of 1280×820 (with 1100×720 the mockup does not fit either).
- Simulated agent for development only: `pnpm dev` and open `/?demo` (`&pc=on`, `&agent=off`); the build does not include it.
- Screenshots (frontend in Chrome with the simulated agent): removed later because they showed the retired Spanish UI; see git history.
