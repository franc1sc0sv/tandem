# T-192 — `docs/STATUS.md` contradicts the backlog

## Context

Failure found by the acceptance agent, part C, round 2 (2026-11-18, `origin/develop` b3841bc). See `docs/reports/acceptance-2026-11-18-c2.md`.

## Failure

Documentation coherence. `docs/STATUS.md`:

- "Open tasks" table: says T-140…T-147, T-160 and T-161 are `todo`; in `docs/tasks/` T-140…T-147, T-150…T-160 are `done`. Only T-027, T-124 (and T-161, see T-193) are still open, with T-088, T-095 and T-096 `blocked`.
- "92 done of 111" and "`T-001`…`T-165`": there are 121 files, 115 `done`.
- "Risks": still lists T-160's flaky tests as known without mentioning T-190 and T-191.
- The cut says `develop` at `509727a`; develop is already at another commit.

## Expected fix

Regenerate STATUS from `docs/tasks/*.md` (counts and table of open ones) and, better, a `scripts/ci/status.sh` script that fails if the header counts do not match the files, run in CI.

> Decision: `status.sh` runs in the `preparar` job of `release.yml`, not in each PR's CI, so that parallel tasks do not have to touch `STATUS.md` and clash with each other; it can be run by hand at any time.
