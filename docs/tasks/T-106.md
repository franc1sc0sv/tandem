# T-106 — Archivos y puertos

## Contexto

DESIGN §8. También es la base de `tandem-files` (T-121).

## Alcance

1. Crate `tandem-files`: transferencia de archivos y carpetas en fragmentos de 1 MiB con BLAKE3 por fragmento y del total, reanudable tras un corte, permisos y fechas conservados donde el sistema lo permita, rutas normalizadas entre Windows y Unix.
2. `files_put { tunnel, local, remote }` y `files_get` sobre el canal de datos (T-101), con progreso.
3. `port_forward { tunnel, local_port, remote_host, remote_port, direction }`: TCP en las dos direcciones, varias conexiones simultáneas, se cierra con el túnel.

## Criterios de aceptación

- [ ] Prueba de propiedades: cualquier árbol de archivos (incluye vacíos, binarios, nombres con espacios y acentos) llega idéntico; corte en cualquier fragmento y reanudación sin repetir lo ya recibido.
- [ ] Port forward con un servidor TCP de eco en las dos direcciones y 20 conexiones a la vez.
- [ ] Puerta de calidad y CI en verde.
