# T-116 — Monitors and scenes screen

## Context

DESIGN §12. Reference mockups (visual and interactive source of truth): `V3-Monitores`, `F-NuevaEscena`, `F-Transacciones`. The screen must look and behave the same as the mockup: same structure, sizes, colors, icons, texts, animations and transitions; everything interactive in the mockup really works against the agent.

## Scope

1. Compatible monitors: real input with a segmented selector with a sliding indicator, owner, events with icons.
2. Dedicated card for "not compatible" (the 32" when it comes back) with its reason.
3. Scenes as cards with an "Active" badge and an "Apply" button; create/edit scene (`F-NuevaEscena`).
4. Step-by-step progress of applying a scene with visible rollback (`F-Transacciones`).

## Acceptance criteria

- [x] Similarity ≥ 0.99 against each listed mockup and state, in the screenshot harness (T-112/T-125), with the screenshots saved in `docs/screenshots/v03/`.
- [x] Everything that is interactive in the mockup works connected to the agent (real IPC) and in demo mode; vitest tests of the logic and of the interactions.
- [x] Mockup animations and transitions present; with `prefers-reduced-motion` they are turned off (test).
- [x] No filler texts or elements without a function (DESIGN §3.8).
- [x] `pnpm test`, `pnpm build`, `pnpm check` and CI green.

## Notes

- Screens: `Monitores.svelte`, `Escena.svelte` (`#/monitores/escena`) and `Progreso.svelte` (`#/progreso`); pure logic in `lib/monitors.ts`, `lib/scenes.ts` and `lib/txn.ts`, with tests.
- Data: the IPC of T-110 (`monitors`, `switch_monitor`, scenes) in `session.rs` and `live.ts`. The agent has no `forget_monitor` nor a way to cancel a power on: with the real agent the screen does not offer "Forget monitor" (`can("forget")` is false) nor "Stop waiting"; demo mode brings the compatible 34" and the "not compatible" 32" (D11), and `txn=run|ok|fail` opens the progress already in that state.
- Screenshots in `docs/screenshots/v03/` (`monitores`, `monitores-entrada-mac`, `escena-*`, `progreso-*`): similarity over the whole screen ≥ 0.99 and worst tile ≥ 0.97 (`progreso-*`: 0.9988 and 0.972). `Progreso.svelte` draws one card per transaction (scene, power and network measurement) and `txn=run` seeds all three. The only thing covered in `F-Transacciones` is in `mockups/README.md`: the "Simulate…", "from the MacBook" and "Stop waiting" buttons.
- `Button` gains `iconSize`, `iconStroke`, `iconLinecap` and the `--btn-lh` variable (`normal` line height in Monitors, like the mockup); `Icon` gains `linecap`.
