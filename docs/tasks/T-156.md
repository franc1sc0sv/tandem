# T-156 — First use on Windows without setup, and a collapsed "Close"

Found by the acceptance agent (part B), flow F1.

## What fails

1. **It does not open by itself on Windows (nor on any non-macOS system).** `maybeFirstRun()` opens the setup only if `setup_get` says `show`, and `SetupView::new(available = cfg!(target_os = "macos"), …)` is false outside macOS. A freshly installed, unpaired Windows machine shows an empty Desk (a single "Windows" machine, no code, no invitation to pair); the setup is only in Settings → "Run setup again → Open". `docs/ACCEPTANCE.md` F1 ("First use: full setup 1→6 on both machines") and D2 (nothing fixed to Mac/PC) ask for the same first use on both systems.
2. **The setup's "Close" button measures 24×2 px** (`.wz-close`, measured at 1100×700, 1280×860 and 1440×900; also in demo mode) and the click lands on the logo ("brand"): it cannot be closed with the mouse; only with Escape or "Go to desk". It is not in the `F-Asis*` mockups either.

## Screenshots

- App: `docs/reports/acceptance/2026-11-18-b/F1-asistente/00-cerrar-colapsado.png`.
- Mockup: `mockups/v03/F-Asis1.dc.html` (without "Close").

## Expected fix

- The first-start guide (`setup.done`) exists on every system; on those that have no permissions to grant, it opens on the "Your desk" step (or the corresponding one) while there is no peer and it has not been finished.
- "Close" recovers its size (or is removed if the mockups do not have it and Escape/"Go to desk" suffice), with visible focus.
- Vitest tests for both systems and a check of the button's box.

## Acceptance criteria

- [x] A new machine without a peer opens the setup by itself, on Windows and on macOS.
- [x] "Close" (if it exists) is clickable with the mouse.
- [x] Quality gate and CI green.

## Notes

- `SetupView.show = !done` on every system (`available` is still macOS only); `maybeFirstRun` opens on permissions (macOS) or on "Your desk" if there is no peer. "Close" comes back as an "x"-icon-only button (`aria-label`, 32 px, visible focus, at the foot of the side panel; difference documented in `mockups/README.md`). Tests in `store.test.ts`, `wizard-ipc.test.ts` and `setup.rs`.
