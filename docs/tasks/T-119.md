# T-119 — 6-step setup

## Context

DESIGN §12. Reference mockups (visual and interactive source of truth): `F-Asis1`, `V3-Setup`, `F-Asis3`, `F-Asis4`, `F-Asis5`, `F-Setup6`. The screen must look and behave the same as the mockup: same structure, sizes, colors, icons, texts, animations and transitions; everything interactive in the mockup really works against the agent.

## Scope

1. Step menu on the left, clickable, with completed ones in green, the current one highlighted and a hover effect.
2. Step 1 This machine (name, color, what it found with a staggered animation), 2 Your desk (pair with a 6-digit code with the other machine), 3 Permissions (really requested and verified, T-090), 4 Keyboard and mouse (no owner: detect activity on each machine), 5 Arrangement and crossing test (T-117), 6 Done (verified summary and MCP command with copy).
3. Remove from the mockup what contradicts DECISIONS (third machine, the service's "Install" button if it does not apply): see `mockups/README.md`.
4. It can be reopened from Settings.

## Acceptance criteria

- [x] Similarity ≥ 0.99 against each listed mockup and state, in the screenshot harness (T-112/T-125), with the screenshots saved in `docs/screenshots/v03/`.
- [x] Everything that is interactive in the mockup works connected to the agent (real IPC) and in demo mode; vitest tests of the logic and of the interactions.
- [x] Mockup animations and transitions present; with `prefers-reduced-motion` they are turned off (test).
- [x] No filler texts or elements without a function (DESIGN §3.8).
- [x] `pnpm test`, `pnpm build`, `pnpm check` and CI green.
