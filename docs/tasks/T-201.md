# T-201 — UI text and mockups in English

## Context

See T-200. The parity check compares the app with the mockup PNGs, so both sides change in one PR.

## Scope

- Every user-visible string in `apps/tandem-ui` (Svelte, TS strings, demo data, tray, palette, notices, errors shown to the user).
- `mockups/v03/*.dc.html` text, and file renames per `docs/GLOSSARY.md`; `mockups/README.md`.
- Regenerate `docs/mockups-png/` (renamed) with `tools/mockup-render`, and `docs/screenshots/v03/` (renamed, `similarity.json`) with `pnpm shots`.
- `tools/mockup-render` (code, comments, file names).
- Update the shots spec and any test that asserts visible text, only as needed for this change. Code identifiers, comments and test names are T-202.

## Acceptance criteria

- [ ] No Spanish visible anywhere in the app (all demo pairs, every screen and state, tray, palette, setup).
- [ ] Mockups in English with the same layout; mockup PNGs regenerated.
- [ ] `pnpm shots --check` passes with no new masks; similarity per screen ≥ 0.99, worst tile ≥ 0.97.
- [ ] `pnpm test`, `pnpm check`, `pnpm build` and CI green.
