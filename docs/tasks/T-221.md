# T-221 — "Update only" does not mean what the switch does

Found by the acceptance agent (part B, round 3, `docs/reports/acceptance-2026-11-18-b3.md`), rule G9 (all visible text in English, and it has to make sense) on screen P11 (`F-Settings`, Updates tab).

## What fails

The switch that turns automatic updates on and off reads **"Update only"** (visible label, `aria-label`, and the matching row in `mockups/v03/F-Settings.dc.html` line 93). It is a word-by-word translation of the Spanish phrase meaning "update by itself". `docs/DECISIONS.md` (2026-11-17, T-122) names it **"Update automatically"**. A user reads "Update only" as "only update" (nothing else) and cannot tell what the switch does.

The same translation pass left other labels that read oddly in English and should be reviewed with it:

- `Band` (Network path cards, three places in `mockups/v03/V3-Network.dc.html`) is the short form of the Spanish word for bandwidth; the screen's own button says "Measure bandwidth". Expected: "Bandwidth".
- `Main` (path chip) next to `Backup`; the code comments and DECISIONS call it "Primary".

- Mockup: `mockups/v03/F-Settings.dc.html`, `mockups/v03/V3-Network.dc.html` (same text, to be fixed together with the app).

## Expected fix

- "Update only" becomes "Update automatically" in `apps/tandem-ui/src/screens/Updates.svelte`, `apps/tandem-ui/src/lib/updates.ts` comments, the demo data, the tests and the mockup `F-Settings`.
- "Band" becomes "Bandwidth" and "Main" becomes "Primary" in the Network screen, its tests and `V3-Network`, unless the part A owner decides to keep them; in that case, record the decision in `docs/DECISIONS.md`.
- Regenerate the reference PNGs (`pnpm shots`) so parity stays at 1.0.
