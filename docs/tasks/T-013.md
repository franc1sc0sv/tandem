# T-013 — macOS: bring windows over from the built-in display

## Scope

With the Accessibility API (AXUIElement): list windows whose frame falls on the built-in display and move them to the main monitor.

## Acceptance criteria

- [x] Compiles on macos CI; manual test documented (below).

## Notes

- Portable logic in `tandem_display::gather` (`plan` / `gather` over the `WindowApi` trait, `FakeWindows` double), with unit and property tests on Linux.
- Rules: a window belongs to the display it overlaps most; the destination is the main external (or the first active non-mirrored external if the main one is the built-in); it keeps its relative position and shrinks if it does not fit; minimized ones are left alone; if one window fails the rest continue. With the built-in off or mirrored there is nothing to do.
- Real backend in `tandem_display::macos::ax` (`AxApi`, direct FFI to ApplicationServices, no new dependencies): applications via `CGWindowListCopyWindowInfo` (layer 0), windows via `AXWindows`, moving with `AXPosition`/`AXSize`; 1 s timeout per app so a hung one does not block. Entry point: `tandem_display::macos::gather_builtin_windows()`.
- Requires the Accessibility permission (S7); without it returns `GatherError::PermissionDenied`. Connecting it to the UI ("Bring windows" button) is left for the UI task.

## Manual test

On the Mac (`ssh mac-runner`, graphical session logged in, with at least one external monitor and the built-in in Extended mode):

1. Grant the Accessibility permission to the terminal that runs the tests.
2. Open two or three windows on the built-in display (one larger than the external monitor if you want to test shrinking) and minimize one.
3. `cargo test -p tandem-display -- --ignored --nocapture lists_windows`: the windows should appear with their app, title and frame.
4. `cargo test -p tandem-display -- --ignored --nocapture gathers_builtin_windows`: the windows move to the main monitor, the minimized one is left alone, and the test reports each move.

## Pending hardware verification

- [ ] `lists_windows` on the Mac: lists the windows of all apps with frames in the same coordinates as `CGDisplayBounds`.
- [ ] `gathers_builtin_windows`: the built-in's windows end up entirely on the main monitor and keep their relative position.
- [ ] A window larger than the destination shrinks and ends up inside it.
- [ ] Without the Accessibility permission it returns `PermissionDenied` (it does not fail silently).
- [ ] Windows in another Space or in full screen: note what macOS does.
