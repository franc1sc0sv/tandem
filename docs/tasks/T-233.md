# T-233 — Spanish file names and `docs/examples`

## Context

Failure found by the acceptance agent, part C, round 3 (2026-11-19, `origin/develop` bbdc245). See `docs/reports/acceptance-2026-11-18-c3.md`. CLAUDE.md: "No Spanish anywhere in the repo", and file names are in English.

## Failure

- `docs/examples/tandem.pc.toml`, `tandem.mac.toml`, `v0.2/tandem.pc.toml`, `v0.2/tandem.mac.toml` have Spanish comments (about 70 lines). They are read by tests (`--check-config`, v0.2 migration), so the TOML keys must not change.
- About 27 files in `docs/screenshots/` have Spanish names, for example `T-041-escena.png`, `T-042-bandeja-compartido.png`, `T-070-permisos-sin-agente.png`, `T-085-sin-confirmar.png`, `T-087-1-esta-maquina.png`, `v01-escena.png`, `v02-propuesta-acomodo.png`. Task files and docs reference them.

## Expected fix

- Translate the comments of the four example files without touching keys or values; run the tests that load them.
- Rename the screenshots to English (`scene`, `tray`, `shared`, `progress`, `unconfirmed`, `this-machine`, ...) with `git mv` and update every reference (`git grep` for the old names).

## Acceptance criteria

- [ ] `docs/examples/**` has no Spanish prose and its tests pass.
- [ ] No file under `docs/screenshots` has a Spanish name and no reference is broken.
- [ ] Quality gate and CI green.
