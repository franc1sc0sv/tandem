# T-079 — Base de perfiles DDC compartida

## Alcance

Reemplazar los perfiles escritos en código (`known_profile` en `crates/tandem-display/src/ddc/switch.rs`) por una base de perfiles en archivos: `profiles/ddc/<PNP>.toml` (por ejemplo `SAM711A.toml`, `SAM7489.toml`) con: id PnP, nombres EDID conocidos, códigos por entrada (`hdmi`, `display_port`, y `hdmi2`/`display_port2` opcionales), lectura que reporta cada entrada (la pista de T-050), notas, quién lo verificó y fecha.
- Los perfiles del repo se embeben en el binario (`include_str!`); el usuario puede agregar los suyos en `<datos>/profiles/ddc/`, que tienen prioridad.
- Búsqueda por id PnP primero; por nombre EDID solo si el nombre no es genérico.
- Migrar los dos perfiles verificados de `docs/research/` (34" SAM711A: HDMI 0x06 / DP 0x09; 32" SAM7489: HDMI 0x05 / DP 0x0F).
- `tandem-ddc profile <monitor>` muestra el perfil que se aplicaría y de dónde sale; `tandem-ddc profile export <monitor>` imprime el TOML para compartirlo.

## Criterios de aceptación

- [ ] Los dos perfiles verificados viven en `profiles/ddc/` y las pruebas de `known_profile` siguen pasando con la base nueva.
- [ ] Un perfil del usuario con el mismo id PnP gana sobre el del repo (prueba).
- [ ] Un archivo de perfil inválido da un error claro con el nombre del archivo, sin tumbar la búsqueda de los demás.
- [ ] docs/dev/ddc-profiles.md: formato y cómo aportar un perfil.
