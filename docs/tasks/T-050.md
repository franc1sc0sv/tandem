# T-050 — Perfil DDC del 32" y código de vuelta del 34"

## Alcance

Con `tandem-ddc` y el usuario mirando: (1) aislar si el 34" vuelve a DP con `0x09` o con `0x0F`; (2) conectar el 32" por DP a la PC, leer su capabilities y encontrar sus códigos HDMI/DP con el mismo procedimiento (siempre con vuelta automática).

## Criterios de aceptación

- [x] Nota en docs/research/ddc-32-*.md y perfiles DDC en la config de ejemplo.

## Notas

Hecho con el usuario el 2026-10-16. 34": HDMI `0x06`, DP `0x09` (aislado). 32" (SAM7489): HDMI `0x05`, DP `0x0F`. Ver `docs/research/ddc-32-odyssey-g5.md`.
