# T-300 — Dangling switch styles in `V3-Machine`

## Context

Finding of the acceptance agent (part A, round 6, `docs/reports/acceptance-2026-11-19-a6.md`), check "T-270 is clean" and rule G7 (every `transition` of the screen's mockup has its equivalent in the app).

T-270 removed the "Allow remote execution" row, the only `.sw` element of `mockups/v03/V3-Machine.dc.html`, but left its four style rules in the same file:

```
29:.sw{width:38px;height:22px;border-radius:11px;background:#2f6a52;position:relative;border:0;cursor:pointer;flex:none}
30:.sw::after{content:"";position:absolute;top:3px;left:19px;width:16px;height:16px;border-radius:50%;background:#e8e8eb}
68:.sw{transition:background .25s}
69:.sw::after{transition:left .25s cubic-bezier(.3,1.4,.5,1)}
```

No element of `V3-Machine` uses the class any more (`grep -n 'class="sw' mockups/v03/V3-Machine.dc.html` finds nothing; the other `V3-*` mockups have no `.sw` rules). The mockup still declares a switch, with its two transitions, for a control the screen no longer has and the app no longer draws. Nothing is visible: the PNG re-renders byte-identical and `machine-b` is 99.99 % / 98.6 %; the motion harness counts computed styles on elements, so it only sees that the mockup went from 13 to 11 signatures. It is still a leftover of the removed row in the source of truth: anyone reading the mockup's CSS to match its transitions (G7) finds a switch that does not exist.

The app side is clean: `Switch.svelte` lost `locked`/`hint` and its `.sw.locked` rule, `Machine.svelte` lost the `.remote` block and the `Switch` import, `svelte-check --fail-on-warnings` reports no unused selector. Observation, not part of this task: the global `.sr-only` utility (`apps/tandem-ui/src/styles/global.css`, T-112) has no user since T-270 removed the locked switch's hint; it is a generic utility, keep it or drop it at will.

Screenshots: app `docs/screenshots/v03/machine-b.png`, mockup `docs/mockups-png/V3-Machine.png`; no diff (identical render, the problem is in the source).

## Expected fix

Delete the four `.sw` rules (lines 29, 30, 68 and 69) from `mockups/v03/V3-Machine.dc.html`. Nothing else changes.
