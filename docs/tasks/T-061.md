# T-061 — Test CI: proptest, coverage and Windows/macOS

## Scope

Add `proptest` to the workspace dependencies and property tests in tandem-core (rollback restores the state for any plan and any failing step; no mode leaves the Mac without a visible screen). Coverage job with `cargo llvm-cov` (informational) in CI.

## Acceptance criteria

- [x] Property tests in tandem-core pass in CI x3.
- [x] Coverage report published as a job artifact.

## Notes

- Tests in `crates/tandem-core/tests/props.rs`. The test executor carries a physical model of the desk (inputs, PC, built-in screen) that only changes with successful steps; checks are made against it and against `State`.
- Properties: the plan reaches the mode's assignment; failing at any step restores the desk (except the PC being on, which is not undone); a clean power off leaves everything on the Mac and the Mac with a screen.
- The generated states are consistent with the wiring (each monitor shows a machine it is wired to). Beyond that, `Step::inverse` of a `SwitchInput` returns `None` and rollback cannot return the monitor: left for whoever hardens the state model.
- `coverage` job in CI with `cargo llvm-cov` (informational, `continue-on-error`): uploads `lcov.info` and the HTML as the `coverage` artifact and leaves the summary on the job page.
