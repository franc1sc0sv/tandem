# T-124 — End-to-end acceptance

## Context

User request (2026-11-16): "everything functional, usable, aesthetically correct according to my instructions, 99 % identical to the mockup with all the animations, tested end to end". It is run by the `acceptance` agent (see `.claude/agents/acceptance.md`).

## Scope

1. Walk through every flow of the app in demo mode and against two real agents on loopback (`--sim-backends`): full setup, pairing, changing the arrangement and testing the crossing, applying scenes, seeing tunnels opened by a test MCP client, measuring the network, settings, palette, notices, trouble states.
2. Screenshots of each step; comparison with the corresponding mockup (≥ 0.99) and review against DECISIONS and the visual rules of DESIGN §12.
3. Each difference or failure becomes a new `T-1xx` fix task (with screenshot, mockup, difference) and is reviewed again until it passes.
4. Final report `docs/reports/acceptance-<date>.md` with all the screenshots (app vs mockup) and the verdict per flow.

## Acceptance criteria

- [ ] All flows pass: functional, similarity ≥ 0.99, animations present, no violations of DECISIONS.
- [ ] Final report published in the repo.
