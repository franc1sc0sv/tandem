# T-209 — Persisted identifiers in English

## Context

The English migration (T-200) kept some Spanish identifiers because they are stored in the user's configuration or shared with the UI: scene ids `trabajo`, `solo-a`, `solo-b`, default scene names "Trabajo" / "Solo A" / "Solo B", the icon id `puesto`, screen ids `pantalla-N`, the retired shortcut keys `solo_mac` / `solo_pc` and `State::solo`. Renaming them blindly would break existing configs.

## Expected fix

- New English ids and names (`work`, `only-a`, `only-b`, "Work", "Only A", "Only B", `desk`, `screen-N`, …).
- On load, migrate old ids to the new ones (config and stored state), write back once, and keep reading the old ones for one release. Tests for the migration both ways (old file → new ids; new file untouched).
- UI and agent use only the new ids.

## Acceptance criteria

- [x] No Spanish persisted identifiers left in code, config defaults or the UI data (except the documented data exceptions: Spanish keyboard labels, Spanish `netsh` output parsing, and the legacy ids that `tandem_core::legacy` reads for one release).
- [x] Migration tested with an old config file.
- [x] Quality gate, `pnpm test`, `pnpm shots --check` and CI green.

## Notes

- Migration: `tandem_core::legacy` (`Desk::migrate_legacy_ids`, `State::migrate_legacy_ids`). It maps scene ids, the default scene names, the `puesto` icon and `pantalla-N` screen ids (also in `[[cables]]`) when reading `tandem.toml`, the stored state and a desk received from an older peer. The config is rewritten once through the existing `legacy_desk` path (not counted as a change); the state is written back on load. A scene whose new id is taken, or a name the user changed, is left alone.
- `Powered::solo` is now `Powered::only`. The retired `ui.toml` shortcut keys `solo_mac`/`solo_pc` stay in `RETIRED` on purpose: they are old on-disk names that are only recognised and dropped, never written.
- UI: only data ids changed (demo scenes `work`, `only-a`, `game`; icon `desk`). Route and tab ids such as `puesto` are part of the UI file renames in T-202.
- Remove `tandem_core::legacy` one release after this one.
