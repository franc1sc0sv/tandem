# T-209 — Persisted identifiers in English

## Context

The English migration (T-200) kept some Spanish identifiers because they are stored in the user's configuration or shared with the UI: scene ids `trabajo`, `solo-a`, `solo-b`, default scene names "Trabajo" / "Solo A" / "Solo B", the icon id `puesto`, screen ids `pantalla-N`, the retired shortcut keys `solo_mac` / `solo_pc` and `State::solo`. Renaming them blindly would break existing configs.

## Expected fix

- New English ids and names (`work`, `only-a`, `only-b`, "Work", "Only A", "Only B", `desk`, `screen-N`, …).
- On load, migrate old ids to the new ones (config and stored state), write back once, and keep reading the old ones for one release. Tests for the migration both ways (old file → new ids; new file untouched).
- UI and agent use only the new ids.

## Acceptance criteria

- [ ] No Spanish identifiers left in code, config defaults or the UI (except the documented data exceptions: Spanish keyboard labels, Spanish `netsh` output parsing).
- [ ] Migration tested with an old config file.
- [ ] Quality gate, `pnpm test`, `pnpm shots --check` and CI green.
