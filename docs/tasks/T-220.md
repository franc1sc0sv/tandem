# T-220 — "Activity detected" is forwarded for the first key only

Found by the acceptance agent (part B, round 3, `docs/reports/acceptance-2026-11-18-b3.md`), flow F1 ("keyboard and mouse detected on each machine"), screen P8 (`F-Setup4`). It is what is left of T-166: the first activity reaches the other window, the second never does.

## What fails

Two real agents, both windows on step 4 "Keyboard and mouse", fresh pair (`docs/reports/acceptance/2026-11-18-b3/harness/t166b.mjs`):

1. A key and a mouse move in A's window: both windows mark A's row "Activity detected" (this is the T-166 fix and it works).
2. A key in B's window afterwards: B's window marks B's row (local), but **A's window never marks B's row**. The final state is A's window with only A marked and B's window with both marked.

The same happens the other way round (B first, then A: B's window never marks A's row; `t166.mjs`, step "vice versa").

## Cause

`crates/tandemd/src/agent/setup.rs`, `Agent::hear`: it records only the first key that arrives (`s.armed && s.heard.is_none()`), and `heard_key` only sends `KeyProbeMsg::Heard` to the other machine when `hear` returned true. Once one machine has been heard, activity on the other one is dropped at the agent, so it is never forwarded to the other window. `KeyProbeStatus.heard` is a single `Option<Machine>`.

## Expected fix

- Track activity per machine (a set, or one flag per machine) instead of a single winner, and forward each machine's first activity to the other one, so both windows converge on "A heard, B heard" whatever the order.
- Keep re-arming on entering the step (state resets).
- Integration test through the IPC (like the T-166 test in `crates/tandemd/tests/wizard.rs`): A then B (and B then A) with both UIs connected; both UIs receive both machines.
- Live UI test with the bridge for the second activity.

## Acceptance criteria

- [x] After activity on A and then on B (and the reverse), both windows mark both rows.
- [x] A test through the IPC that fails before the fix.
- [x] Quality gate and CI green.
