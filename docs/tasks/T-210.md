# T-210 — Final English sweep and a CI guard so Spanish never comes back

## Context

See T-200. The per-area tasks left a tail: Spanish comments in `.gitignore`, `vite.config.ts` and the example configs, old Spanish names in task files, Spanish file names under `docs/screenshots/`, and no automatic check.

## Scope

- Translate what is left, accented and unaccented, in comments, strings, docs, file names and branch names in docs. The text files of `docs/reports/acceptance/` (harness scripts, logs) are translated too; only its images are left as captured.
- Make `docs/GLOSSARY.md` English-only: a term list, with no Spanish column and no old-name rename map.
- `scripts/ci/english.sh`: fails on accented Spanish characters or a list of common Spanish words in tracked text files and in file names. Exceptions live in `scripts/ci/english-allow.txt` (path glob plus an optional line regex). It skips binary files, prints `file:line` per hit and runs in the same CI step as `privacy.sh`, `safety.sh` and `tasks.sh`.
- Close T-205 (its final sweep).

## Acceptance criteria

- [x] `scripts/ci/english.sh` passes on the tree and fails on a crafted Spanish line (checked by hand, then reverted).
- [x] The guard runs in `.github/workflows/ci.yml`.
- [x] `docs/GLOSSARY.md` is English-only.
- [x] Remaining Spanish is only the data listed in `scripts/ci/english-allow.txt`, each with a short English comment where it lives.
- [x] T-205 is `done`.
- [x] Quality gate, `pnpm test`, `pnpm check` and `pnpm build` green.

## Notes

- Allowed data: Spanish ISO keyboard labels (`keymap.rs`), Spanish `netsh` and `wsl` output matched by parsers, Unicode test inputs, the "n with tilde" naming the key under test, and the old scene, icon and screen ids that the T-209 migration still recognises (`tandem-core/src/legacy.rs` and the tests that feed it).
- The old screenshots in `docs/screenshots/` (T-0xx, v01, v02, t122) showed the retired Spanish UI and had Spanish names, so they were deleted (still in git history); the task files that cited them keep the text only. Task files that cited old Spanish mockup, screen, route and acceptance-evidence names now use the current ones.
- Renamed a few Spanish values: two tracing field names, the sample machine name, local variable and file names in tests, and the reserved-name tests that used a lowercase Spanish word (now `nul`).
- Spanish test names were renamed in the crates and in every task file that cites them; a few tests cited by tasks no longer exist and are described in prose.
- Acceptance evidence paths cited by tasks now use the current English directory names.
- The guard skips only its own two files; an underscore or hyphen ends a word, so `snake_case` names are checked word by word. Case: lowercase and capitalised words, except "Del" and "Con" (the Del key, the device name CON) and anything after a dot (`Math.sin`).
