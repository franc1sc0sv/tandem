# T-351 — The UI must not freeze on `launchctl`

## Context

Seen on the real desk on 2026-11-20 (v0.3.1), recorded in the notes of T-350: `lsappinfo` showed
`Contents/MacOS/tandem-ui` in state `exited-with-subordinates` with a dimmed Dock icon whose Quit
did nothing, no `tandemd` in `ps`, and `/bin/launchctl kickstart -k gui/501/com.franc1sc0sv.tandem.tandemd`
stuck for 41+ s. The PC lost the Mac agent at 09:53:22 local. Recovery needed a manual
`pkill` of the stuck `launchctl` and a plain `launchctl kickstart`.

Reading of the code (see T-350 notes):

1. `apps/tandem-ui/src-tauri/src/app.rs` `setup()` calls `install_agent()` →
   `launch_agent::install_from` → `ensure()` synchronously on the main thread, before any window
   exists. With the plist correct and the job loaded without a process (launchd holding it for
   `ThrottleInterval` 30 s), `ensure` runs `launchctl kickstart -k`. `SystemLaunchd::run` uses
   `Command::output()` with no timeout, so a hung `launchctl` freezes the UI.
2. `agent_restart` ("Restart agent") is a synchronous `#[tauri::command]` on the main thread: same
   exposure. `revive_agent` uses `spawn_blocking` but without a timeout.

## Goal

No `launchctl` call can freeze the UI or keep it from quitting, and starting a loaded agent with
no process does not use `-k`.

## Approach

- Every `launchctl` call runs off the main thread with a timeout (kill the child on expiry and
  report it); `setup()` does not wait for the agent install to show the window or the tray.
- `ensure`/`revive`: with the job loaded and no process, `kickstart` without `-k`; keep `-k` only for
  a deliberate restart of a running agent.
- The restart command becomes async.
- Portable decisions and the timeout wrapper tested on Linux with the `Launchd` test double
  (a fake that hangs), per docs/TESTING.md.
- Find out why `kickstart -k` hung (throttle, the agent's AppKit run loop vs SIGTERM,
  `exit timeout = 5`) and record it in Notes.

## Acceptance criteria

- [ ] No `launchctl` call on the UI's main thread; all with a timeout; tests with a hanging double.
- [ ] `kickstart -k` only for a running agent; tests for the loaded-without-process case.
- [ ] Quality gate and CI green on the three platforms.

## Pending hardware verification

- [ ] Kill `tandemd`, open Tandem within the 30 s throttle: the window appears at once and the
      agent comes back without manual steps.
- [ ] "Restart agent" with a stuck `launchctl` (simulated) leaves the UI responsive and quittable.
