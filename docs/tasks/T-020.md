# T-020 — Modelo de eventos de entrada y tablas de teclas

## Alcance

`tandem-input::event`: tipos de evento (tecla por HID usage, botones, movimiento relativo y absoluto, scroll v120 y píxel, modificadores), y tablas HID ↔ keycode Mac ↔ scancode Windows (crate `keycode`). Política de reasignación de modificadores configurable por dirección (docs/research/input-engine.md). Conjunto de teclas presionadas con `release_all()`.

## Criterios de aceptación

- [ ] Pruebas de ida y vuelta HID↔Mac↔Windows para todas las teclas de un teclado ISO español.
- [ ] Pruebas de la reasignación por defecto Cmd→Ctrl, etc.
- [ ] Sin dependencias de plataforma en este módulo.
