# T-140 — Cursor and edge flash on the Desk (demo)

## Context

Finding of the acceptance agent (part A, 2026-11-18), items G7 and P1. `V3-Puesto` animates the cursor with `@keyframes cur` (7 s: from the MacBook to the 34" and back) and the edge flash with `eg` (7 s). The app does it with cursor samples (`watchCursor`) and `.edge.on` (`eg`, 1 s per crossing), but in the demo without `still` (`?demo`, `pnpm dev`) the path restarts every ~1.5 s: measured at 100 ms for 9 s, `.curdot` goes from `left: 16 %` to `25 %` and jumps back to 16 % (6 cycles), never reaches the 34" and `.edge.on` is not activated even once in 16 s. The mockup's animation (crossing + flash) is never seen.

Probable cause: the `$effect` of `apps/tandem-ui/src/screens/Puesto.svelte` (live cursor) depends on `scene`, a `$derived` that returns a new object on every change of `desk`; the demo publishes a new `desk` on every tick (`TICK_MS = 1500` in `demo.ts`), so the effect unsubscribes and calls `watchCursor` again (which starts `t0` over). With the real agent the same pattern would request `WatchCursor { on }` again every time any desk topic changes: also review that.

## Scope

1. Make the cursor subscription be redone only when what actually affects it changes (visibility, `cursor` capability, arrangement geometry), not on every desk snapshot.
2. Test (vitest) that counts the calls to `watchCursor` over several demo ticks: just one.
3. Check in demo (without `still`) that within 7 s the cursor reaches the 34", the flash is activated once per crossing and with `prefers-reduced-motion: reduce` the cursor is not animated.

## Acceptance criteria

- [x] In `?demo`, the dot goes through the mockup's 7 s (reaches `left ≥ 60 %`) and `.edge.on` appears on crossing, without restarts.
- [x] `watchCursor` is called once per mount of the screen, with a test.
- [x] Quality gate and CI green; the `puesto` screenshots do not change.

## Notes

Evidence: `docs/reports/acceptance-2026-11-18-a.md`, item G7/P1.

Fixed in `Puesto.svelte`: the cursor effect depends on a by-value fingerprint of the geometry (`geometry`) and reads `scene`/`layout` with `untrack`, so it no longer calls `watchCursor` again on every desk snapshot. Tests in `puesto.test.ts` (a single call in 10 s of ticks; the dot reaches ≥ 60 % and `.edge.on` is activated).
