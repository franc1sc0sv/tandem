# T-024 — Input capture on Windows

## Scope

`tandem-input::windows::capture`: LL hooks on a dedicated thread with a non-blocking queue, Raw Input for deltas, filter for injected events, hook watchdog, filter for AltGr's fake Ctrl, Per-Monitor-V2 DPI.

## Acceptance criteria

- [x] Compiles for windows-gnu and on windows CI.
- [x] Test on the PC via powershell/interop documented.

## Notes

- Portable logic (tested on Linux): `HookFilter` (what is swallowed), `Translator` (injected filter, AltGr's fake Ctrl, scancode → HID, wheel and buttons, Raw Input deltas), `Watchdog` and the `run_pipeline` loop, which talks to the system through the `HookControl` trait (in tests, a double). Only `windows::capture::sys` (`cfg(windows)`) touches Win32: `WindowsCapture`.
- Two threads: the hooks one (`WH_KEYBOARD_LL`, `WH_MOUSE_LL` and a message-only window with Raw Input `RIDEV_INPUTSINK`, maximum priority) only copies the structure, decides and enqueues into an unbounded `mpsc`; the processing one translates and calls the `sink`.
- Contract with the session (T-026): `MotionRelative` from Raw Input always (physical pixels, no acceleration) and `MotionAbsolute` with the real cursor position while there is no grab. With grab, everything is swallowed and reported all the same. `set_grab(bool)` and `warp(Point)` are the methods that T-026's `Capture` trait asks for; once T-026 lands in `develop`, `impl Capture for WindowsCapture` is direct.
- What is injected (`LLKHF_INJECTED`/`LLMHF_INJECTED`, and Raw Input without `hDevice`) goes through to the local system and is not reported: this way there is no echo with T-025's injection. T-025 marks everything it injects with `crate::windows::TANDEM_EXTRA_INFO` in `dwExtraInfo`; the capture uses that same constant (not a copy) to recognize it.
- A key or button pressed while input was local is released locally even if the grab is already on (otherwise it would stay stuck in Windows).
- AltGr: the left Ctrl with scancode `0x21D` is discarded; if it does not carry one, the one that arrives right before right Alt with the same `time` and the same direction. Each left Ctrl is held until the next event or 10 ms.
- Passive watchdog: it never injects anything. A probe with `SendInput` would reset Windows's idle counter (`GetLastInputInfo`), like a "mouse jiggler", and the PC would never reach auto-lock, the screensaver, monitor power-off or suspend. The reference is Raw Input (`RIDEV_INPUTSINK`) of keyboard (`usUsage 0x06`, only for this) and mouse, from real devices (`hDevice != 0`; a mouse without movement does not count): if there is real input of one kind and that kind's hook sees nothing for `hook_timeout` (1 s), both hooks are reinstalled. The same window is the tolerance between the hook's event and Raw Input's, which arrive in any order. Without real input, `Watchdog::tick` never acts.
- NumLock and Pause both arrive with scancode `0x45` (NumLock with the extended mark); Ctrl+Pause arrives as `VK_CANCEL`; media keys without a scancode are resolved by virtual key code. The fake Shifts `E0 2A`/`E0 36` are discarded.
- `ensure_per_monitor_v2()` declares the process Per-Monitor-V2 when the capture starts (or checks that it already is).
- Out of scope: hiding the cursor while there is a grab (it stays still but visible) and input in elevated windows/the secure desktop (T-027). If with an elevated window in the foreground Raw Input still arrives but the hooks do not, the watchdog would reinstall the hooks once per second while typing; it is harmless, but worth reviewing with T-027.

## Test on the PC (interop)

```
cargo build -p tandem-input --bin tandem-capture --target x86_64-pc-windows-gnu
mkdir -p /mnt/c/Users/PC/AppData/Local/Temp/tandem
cp "$CARGO_TARGET_DIR"/x86_64-pc-windows-gnu/debug/tandem-capture.exe /mnt/c/Users/PC/AppData/Local/Temp/tandem/
cd /mnt/c/Users/PC/AppData/Local/Temp/tandem
powershell.exe -NoProfile -Command '& "$env:LOCALAPPDATA\Temp\tandem\tandem-capture.exe" --seconds 15'
# With grab (local input comes back by itself; 30 s cap):
powershell.exe -NoProfile -Command '& "$env:LOCALAPPDATA\Temp\tandem\tandem-capture.exe" --grab-after 3 --grab-for 5'
```

Done on 2026-10-15 without grab: the hooks and Raw Input install, `MotionAbsolute` arrives in physical pixels (with negative x on the left monitor) and `MotionRelative` is consistent (in 8 s, Raw Input added +470 px in x and the cursor moved +468), and the watchdog did not reinstall anything.
