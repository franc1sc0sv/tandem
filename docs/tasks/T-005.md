# T-005 — Gestor de enlaces múltiples y política de planos

## Alcance

`tandem-link::manager`: mantiene conexiones candidatas por enlace (USB4, Ethernet, Wi-Fi) según configuración, ping de salud cada 1 s, prioridad USB4 > Ethernet > Wi-Fi, conmutación inmediata del enlace activo y evento de cambio.
Política de planos (DESIGN §6): el plano de datos solo se habilita sobre enlaces de cable; API `data_plane_available()` y rechazo explícito si se pide sobre Wi-Fi. Sin interruptor para forzarlo.

## Criterios de aceptación

- [ ] Pruebas con enlaces simulados (sockets loopback en distintos puertos): caída del preferido → conmutación < 1.5 s; vuelta del preferido → regresa.
- [ ] Prueba: pedir el plano de datos con solo Wi-Fi activo devuelve error.
- [ ] Eventos de cambio de enlace emitidos en orden.
