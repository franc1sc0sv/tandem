# T-095 — Monitors with the custom firmware

## Context

Replaces T-088 and all the monitor control removed in T-092. Design in `docs/DESIGN.md` §8. Reference protocol: `personal-projects/monitor-firmware` (`client/src/monitor_events/protocol.py`, `notes/re-findings.md`).

## Scope (to be confirmed when the firmware is ready)

1. `tandem-monitor` crate: `MonitorBus` trait (Get/Set VCP) with Windows backends (`dxva2`) and a test double; firmware protocol: detection (`0xEA`), events (`0xEB`–`0xED`), live state (`0xEE`), input switch with verdict (`0x60` + `switch-done`/`switch-failed`).
2. Single reader per monitor in the agent with a DDC channel; events distributed to the other machine over the control plane.
3. Monitor modes and dragging back in the UI; the input geometry takes out the screens that show the other machine.
