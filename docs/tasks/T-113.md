# T-113 — Desk screen (home)

## Context

DESIGN §12. Reference mockups (visual and interactive source of truth): `V3-Puesto`. The screen must look and behave the same as the mockup: same structure, sizes, colors, icons, texts, animations and transitions; everything interactive in the mockup really works against the agent.

## Scope

1. Cards for the two machines (no colored line on top) with system, state, resource sparklines and color dot.
2. Live link strip between them: active path, p50/p99 latency, pulse that follows real traffic (events/s).
3. **Live desktops at real scale** (physical proportion of each screen, same calculation as the arrangement), with the cursor dot at 30 Hz and a flash when crossing the edge (`CursorSample`, subscription only while the window is visible).
4. Scenes with thumbnails, active scene marked and apply button; editing with icon buttons.
5. Power on/off button for the other machine when applicable (transaction with progress, `F-Transacciones`).

## Acceptance criteria

- [x] Similarity ≥ 0.99 against each listed mockup and state, in the screenshot harness (T-112/T-125), with the screenshots saved in `docs/screenshots/v03/`.
- [x] Everything that is interactive in the mockup works connected to the agent (real IPC) and in demo mode; vitest tests of the logic and of the interactions.
- [x] Mockup animations and transitions present; with `prefers-reduced-motion` they are turned off (test).
- [x] No filler texts or elements without a function (DESIGN §3.8).
- [x] `pnpm test`, `pnpm build`, `pnpm check` and CI green.

## Notes

- Similarity of `V3-Puesto` (whole screen; only the empty gap of "Add machine" is covered, D1): 99.99 %, worst tile 98.4 %. Screenshots in `docs/screenshots/v03/`.
- Power on and Power off of the other machine go inside its card (captain's decision, `docs/DECISIONS.md`); there is no separate power card. The step-by-step progress panel (`F-Transacciones`) belongs to T-116; here the button shows "Powering on…" / "Powering off…" while the agent responds.
- The link pulse follows the live cursor's events per second (the agent does not yet send its own traffic counter); `V3-Puesto` only draws the input p99, so p50 is not added.
- The desktop measurements come from the arrangement's `draw` with another canvas; the mockup draws the laptop by hand 0.7 % lower and the monitor 0.5 % taller (constants in `lib/puesto.ts`).
- The app screenshots use a macOS user agent (the mockups show ⌘K); the palette is opened with `Meta+k` in the harness.
