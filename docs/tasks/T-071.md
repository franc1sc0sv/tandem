# T-071 — Windows installer (.msi/NSIS) with tandemd

## Scope

Packaging for Windows with the Tauri bundler: installer that includes `tandemd.exe`, registers it to start with the user's session (scheduled task or Run key; the SYSTEM service mode of T-027 is left as a later improvement), creates the initial config and uninstalls cleanly. CI job on windows-latest that builds the installer and uploads it as an artifact. Authenticode signing optional through environment variables (user's decision, documented).

## Acceptance criteria

- [x] The CI job produces the installer as an artifact.
- [x] The auto-start registration and the uninstall are tested (unit or CI script).
- [x] docs/dev/install-windows.md with installation, auto-start and signing.

## Notes

- NSIS installer (not MSI: WiX asks for administrator and adds nothing for a per-user install), `currentUser` mode in `%LOCALAPPDATA%\Tandem`. Bundle config kept separate in `apps/tandem-ui/src-tauri/windows/installer.conf.json` so the UI's normal build does not require the sidecars.
- Startup: `HKCU` `Run` key (value `tandemd`) pointing to `tandemw.exe`, a launcher without a console that starts `tandemd.exe` with `CREATE_NO_WINDOW`. `tandemd --install` registers it (idempotent, creates the initial config if missing and never overwrites it); `tandemd --uninstall` removes it.
- Tests: unit (`install` with a registry double, `proptest` for convergence, CLI), launcher integration, round trip of the real registry in the Windows CI and `tools/windows/installer/test-installer.ps1` (install, reinstall, uninstall) in the `installer (windows)` job.
- Optional Authenticode signing through `TANDEM_WINDOWS_CERT_THUMBPRINT` / `TANDEM_WINDOWS_SIGN_COMMAND`; without a certificate it is not signed.
