# T-071 — Instalador Windows (.msi/NSIS) con tandemd

## Alcance

Empaquetado para Windows con el bundler de Tauri: instalador que incluye `tandemd.exe`, lo registra para arrancar con la sesión del usuario (tarea programada o clave Run; el modo servicio SYSTEM de T-027 queda como mejora posterior), crea la config inicial y desinstala limpio. Job de CI en windows-latest que construye el instalador y lo sube como artefacto. Firma Authenticode opcional por variables de entorno (decisión del usuario, documentada).

## Criterios de aceptación

- [x] El job de CI produce el instalador como artefacto.
- [x] El registro de arranque automático y la desinstalación están probados (unidad o script de CI).
- [x] docs/dev/install-windows.md con instalación, arranque automático y firma.

## Notas

- Instalador NSIS (no MSI: WiX pide administrador y no aporta nada para una instalación por usuario), modo `currentUser` en `%LOCALAPPDATA%\Tandem`. Config del bundle aparte en `apps/tandem-ui/src-tauri/windows/installer.conf.json` para que el build normal de la UI no exija los sidecars.
- Arranque: clave `Run` de `HKCU` (valor `tandemd`) apuntando a `tandemw.exe`, lanzador sin consola que arranca `tandemd.exe` con `CREATE_NO_WINDOW`. Lo registra `tandemd --install` (idempotente, crea la config inicial si falta y nunca la sobrescribe); `tandemd --uninstall` lo quita.
- Pruebas: unidad (`install` con doble del registro, `proptest` de convergencia, CLI), integración del lanzador, ida y vuelta del registro real en el CI de Windows y `tools/windows/installer/test-installer.ps1` (instalar, reinstalar, desinstalar) en el job `instalador (windows)`.
- Firma Authenticode opcional por `TANDEM_WINDOWS_CERT_THUMBPRINT` / `TANDEM_WINDOWS_SIGN_COMMAND`; sin certificado no se firma.

## Verificación en hardware pendiente

- [ ] Instalar en la PC real: sin ventana de consola al iniciar sesión y `tandemd` en *Aplicaciones de inicio*.
- [ ] La UI instalada se conecta al `tandemd` que arrancó con la sesión.
