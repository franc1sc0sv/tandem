# T-073 — Emparejamiento desde la UI

## Alcance

Flujo de emparejamiento de DESIGN §9 de punta a punta: comando UI→agente para iniciar, el agente descubre al otro y muestra el código de 6 dígitos (T-003) en las dos UIs, el usuario confirma en ambas, se guarda la confianza. Pantalla de emparejamiento con el estilo del mockup (sobrio, visual). Desemparejar desde la UI.

## Criterios de aceptación

- [ ] Prueba con dos agentes: iniciar → mismo código en ambos lados → confirmar en ambos → quedan emparejados; rechazar en uno → ninguno queda emparejado.
- [ ] Pruebas de frontend de la pantalla de emparejamiento.
- [ ] Captura en el PR (modo demo).
