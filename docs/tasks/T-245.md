# T-245 — "The mouse and keyboard also on UAC prompts and at sign-in"

## Context

Finding of the acceptance agent (part A, round 4, `docs/reports/acceptance-2026-11-19-a4.md`), rule G9 (visible text in correct English) and P3 (`V3-Machine` parity of the texts that are not data).

With T-027 the "Protected screens" module becomes active on a real Windows machine, and its line on the machine page is the agent's `detail` (`crates/tandemd/src/modules.rs`, `impl Module for SecureDesktop`):

> The mouse and keyboard also on UAC prompts and at sign-in

The sentence has no verb. `V3-Machine` (and the demo, `apps/tandem-ui/src/lib/store/demo.ts`) say:

> The mouse and keyboard also work on UAC prompts and at the sign-in screen.

The demo screenshots use the demo text (`docs/reports/acceptance/2026-11-19-a4/new-screens/machine-windows-protected-screens.png`), so `pnpm shots` cannot catch it; only the real agent shows it. T-221 fixed the other mistranslated strings but not this one.

## Expected fix

- Use the `V3-Machine` sentence in `SecureDesktop::detail`.
- A test in `modules.rs` that pins the text (as for the other modules' lines), so the agent and the mockup cannot drift again.

## Acceptance criteria

- [ ] The agent's Protected screens line is "The mouse and keyboard also work on UAC prompts and at the sign-in screen."
- [ ] Test added; quality gate and CI green.
