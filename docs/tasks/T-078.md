# T-078 — Calibration confirmation from the other machine

## Scope

Implement T-077's real `Confirmer` using the two machines: when the PC sends a monitor to the Mac's input (or the other way round), the target machine's agent shows on **that** monitor a full-screen page with a big button ("Do you see this? Click") and answers over the control plane if the click arrives before the timeout.
- New control messages in `tandem-proto` (show/hide the calibration probe, result).
- In the UI, the full-screen probe window on the indicated monitor (identified by EDID), in the mockup's sober style.
- If there is no peer (other machine off or unpaired), a local fallback `Confirmer`: the same machine asks through the UI "Did the monitor change?" with Yes/No.

## Acceptance criteria

- [x] Test with two agents on loopback and simulated monitors: T-077's engine calibrates a monitor using remote confirmation end to end.
- [x] With no click within the deadline, it counts as not visible and the probe disappears.
- [x] Frontend tests of the probe window; screenshot in the PR (demo mode).

## Notes

- Protocol v6 (`tandem-proto`): `ControlMsg::{ShowProbe, HideProbe, ProbeResult}` between agents, with `CalibrationProbe` (monitor by EDID: manufacturer, product, serial and name; input; `ProbeAsk::Candidate { code }` or `UserSwitch`; deadline in ms) and `ProbeOutcome::{Seen, Unseen, Failed}`. For the UI, `AgentToUi::Probe(ProbeEvent::{Show, Hide})` with `ProbePlace::Monitor { screen }` (full screen, with the monitor's place if the agent knows it) or `ProbePlace::Question` (fallback), and `UiCommand::AnswerProbe { id, seen }`.
- `tandemd::calibration`: `ProbeBoard` (this machine's UI probes, like `ManualSwitcher`: removed on answering, on reaching their deadline or when the future is dropped) and `AgentConfirmer::new(agent, home)`, the real `Confirmer` for T-080. `home` is this machine's input on the monitor (on the PC, DisplayPort): that probe is shown by this UI; the one for the other input is requested from the peer with `PeerLink::show_probe`. If there is no peer, or the peer has no window open (`Failed`), this UI asks "Did the monitor change?" with Yes/No. With no window on either, the calibration fails with a clear error instead of trying 30 codes blindly.
- The deadline is enforced by whoever shows the probe (it answers `Unseen` and removes it), even if the `HideProbe` from the calibrating side is lost; if the calibrating side stops waiting (its deadline passed or it cancelled) it sends `HideProbe` and the probe is removed at that moment.
- `peer::serve` handles each probe in its own task: waiting for a click does not hold up the orchestrator's steps on the same stream (test). When the stream closes, the probes still on screen are removed.
- The monitor is looked up by EDID in the machine's topology (`topology::locate`, `DesktopControl::locate`): manufacturer and product have to match; serial and name only break ties; if several identical ones remain, it does not guess. While the probe is on screen it looks again every 500 ms (the system takes a while to put the monitor on the desktop after its input is changed) and the UI moves it. Without topology (Linux, tests) the UI looks it up by the EDID name and, failing that, uses the primary screen.
- UI: `probe.html` is a borderless, always-on-top window that covers the monitor (`tandem_ui::probe` chooses the monitor: pixels on Windows, points on macOS) with a big button and the deadline running out; the app opens and closes it with each `Show`/`Hide`. The fallback question goes in the main window's notice, which comes to the front. Demo mode: `/probe.html?demo` (`&ask=switch`, `&input=dp`, `&monitor=…`) and `/?demo&probe=question`. Screenshots: removed later because they showed the retired Spanish UI; see git history.
- Tests: end to end in `tandem-sim` (`tests/calibration.rs`: the 32" with the Mac confirming the HDMI one and the PC the DP one; the 34" with several codes with no click that time out at 8 s and are removed; without the other machine, the PC asks in its window) and over real QUIC on loopback with clicks through the IPC (`tandemd/tests/network.rs`). Plus unit tests of the board (click, deadline, cancellation, no UI, monitor that appears), of the protocol between agents, of the `Confirmer`, of the IPC, of the UI session, of `topology::locate`, of the monitor choice (with properties) and of the frontend (`src/probe.test.ts`).
