# T-120 — Tray, trouble states, notices, settings and palette

## Context

DESIGN §12. Reference mockups (visual and interactive source of truth): `V3-Tray`, `V3-States`, `F-Notices`, `F-Settings`, `F-Palette`. The screen must look and behave the same as the mockup: same structure, sizes, colors, icons, texts, animations and transitions; everything interactive in the mockup really works against the agent.

## Scope

1. Menu bar / tray with a mini summary and quick actions.
2. Trouble states: no agent, the other machine off or lost, link down, permissions revoked; each with the action that fixes it.
3. Uniform notices (toasts): config change from the other machine with "Undo" (T-099), path change, transfer with progress, tunnel opened by Claude.
4. Settings with tabs with icons: Desk and machines (rename, change the other machine = pair again, leave desk), Shortcuts (record combination), Keyboard and mouse, Updates (T-122), Advanced (config file, logs, MCP server).
5. ⌘K palette (if it was not completed in T-112).

## Acceptance criteria

- [x] Similarity ≥ 0.99 against each listed mockup and state, in the screenshot harness (T-112/T-125), with the screenshots saved in `docs/screenshots/v03/`.
- [x] Everything that is interactive in the mockup works connected to the agent (real IPC) and in demo mode; vitest tests of the logic and of the interactions.
- [x] Mockup animations and transitions present; with `prefers-reduced-motion` they are turned off (test).
- [x] No filler texts or elements without a function (DESIGN §3.8).
- [x] `pnpm test`, `pnpm build`, `pnpm check` and CI green.
