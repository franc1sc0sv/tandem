# T-120 — Bandeja, estados difíciles, avisos, ajustes y paleta

## Contexto

DESIGN §12. Mockups de referencia (fuente de verdad visual e interactiva): `V3-Bandeja`, `V3-Estados`, `F-Avisos`, `F-Ajustes`, `F-Paleta`. La pantalla debe verse y comportarse igual que el mockup: misma estructura, tamaños, colores, íconos, textos, animaciones y transiciones; todo lo interactivo del mockup funciona de verdad contra el agente.

## Alcance

1. Barra de menú / bandeja con mini resumen y acciones rápidas.
2. Estados difíciles: sin agente, la otra máquina apagada o perdida, enlace caído, permisos revocados; cada uno con la acción que lo arregla.
3. Avisos (toasts) uniformes: cambio de config desde la otra máquina con «Deshacer» (T-099), cambio de camino, transferencia con progreso, túnel abierto por Claude.
4. Ajustes con pestañas con íconos: Puesto y máquinas (renombrar, cambiar la otra máquina = emparejar de nuevo, salir del puesto), Atajos (grabar combinación), Teclado y mouse, Actualizaciones (T-122), Avanzado (archivo de config, logs, servidor MCP).
5. Paleta ⌘K (si no quedó completa en T-112).
