# T-170 — Execution environments and phrases that do not follow each machine's system (demo)

## Context

Finding of the acceptance agent (part A, round 2), rule G2 ("nothing fixed to Mac/PC"). In `?demo=mac-mac` the Tunnels screen shows, in the tunnel "Monitors crate (T-097)", that the destination **Mac mini** runs in "WSL · Ubuntu", and the same in the tunnels "Train style LoRA" and "Tunnels in tandemd". In `?demo=win-win` the tunnel "Review PR" says "zsh" on a Windows machine. Each tunnel's environment is written by hand in `apps/tandem-ui/src/lib/store/demo.ts` (`t("t97", …, "WSL · Ubuntu", …)`, `t("pr", …, "zsh", …)`, `t("comfy", …, "Windows", …)`), without looking at the destination machine's system. The title "Review PR #66 on Windows" is also fixed.

In addition, the Monitors module phrase of a Mac (`modulesOf`, the line that says there is only a DDC channel over HDMI while the monitor shows the Mac, built with `name.split(" ")[0]`) builds "the MacBook" or "the Mac" by cutting the name, and for "Mac mini" it comes out as "shows the Mac" (in `?demo=mac-mac#/machine/b`).

App screenshot: `docs/reports/acceptance/2026-11-18-a2/tunnels-mac-mac-wsl/app.png` (there is no mockup: `V3-Compute` only draws the Mac + PC pair).

## Scope

1. Make each demo tunnel's environment come from the destination machine's system: `WSL · Ubuntu` or `PowerShell` if it is Windows, `zsh` if it is macOS. The `mac-win` pair stays identical to today's (similarity of `tunnels*` unchanged).
2. Remove "on Windows" from the demo's review tunnel title (or derive it from the system), and fix the Monitors module phrase so that it uses the machine's full name, without an article or a word cut ("shows MacBook Pro" / "the monitor shows MacBook Pro").
3. Test (vitest): with the three demo pairs, no macOS machine shows "WSL", "PowerShell" nor "Windows" in Tunnels and Machine, and no Windows machine "zsh".

## Acceptance criteria

- [x] `?demo=mac-mac` and `?demo=win-win`: no environment, title or phrase mentions a system that the machine does not have.
- [x] `tunnels*`, `machine-*` and `desk` stay at ≥ 0.99 / ≥ 0.97.
- [x] Quality gate and CI green.
