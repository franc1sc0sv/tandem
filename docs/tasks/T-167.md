# T-167 — Each machine's row in the tray

Found by the acceptance agent (part B, round 2, `docs/reports/acceptance-2026-11-18-b2.md`), flow F14, screen P14 (`V3-Tray`) and rule G2 (nothing fixed to Mac/PC).

## What fails

1. With a tunnel with one process running, the tray says **"1 tunnels"** (`docs/reports/acceptance/2026-11-18-b2/F14-tray/02-tray-with-tunnel.png`). The plural is fixed.
2. `apps/tandem-ui/src/Tray.svelte` (each machine's row) paints "macOS" if `m.os === "macos"` and, otherwise, "N tunnels". It is a decision by operating system: a tunnel whose destination is a Mac is never counted, and in a macOS+macOS pair both rows say "macOS" with no count. D2/A1 and G2 ask that nothing depend on which machine is the Mac or the PC. (This last point comes from reading the code; it was not measured with a macOS+macOS pair in the tray.)

- App: `docs/reports/acceptance/2026-11-18-b2/F14-tray/02-tray-with-tunnel.png`.

## Expected fix

- Correct singular and plural ("1 tunnel", "2 tunnels", "0 tunnels" or "no tunnels").
- Each row shows the same kind of data for both machines (system and count of tunnels to it), without branches per operating system; with the mockup's pair it looks the same as today.
- Tray test with Windows+Windows and macOS+macOS pairs and one tunnel to each.

## Acceptance criteria

- [x] "1 tunnel" in the singular.
- [x] The count does not depend on the machine's operating system.
- [x] `V3-Tray` similarity not dropping below 0.99 / 0.97.
