# T-112 — UI base v0.3

## Context

DECISIONS A3, A4, D15, D16; DESIGN §12. Reference mockups: all those in `mockups/v03/` (the sidebar comes from `V3-Puesto`, `V3-Acomodo`, `V3-Red`).

## Scope

1. Migrate `apps/tandem-ui` to **Svelte 5 + Vite + TypeScript** inside Tauri 2 (pnpm). Keep and keep testing the existing pure logic (pairing, onboarding, permissions, shortcuts, bridge).
2. **Visual system** taken literally from the mockups: color tokens (background `#0e0f12`, cards `#15161a`, borders `#25272d`, text `#e8e8eb`, muted `#9a9da6`, blue accent `#7aa7e6`, violet `#a99be8`, green `#6cc59a`, amber `#d9a75a`, red `#e07a6f`), Inter + JetBrains Mono (bundled locally, no Google Fonts in the app), radii, shadows. Components: `Button` (variants `pri`, `ghost`, `danger`, `sm`, `ic`; fixed height, always an icon, elevation on hover, glow on `pri`, visible focus), `Segmented` with a sliding indicator, `Switch`, uniform status `Chip` (dot + text), `Card` (no colored line on top), line icons (own SVG set, same stroke as the mockups), rings and sparklines.
3. **Animations**: card entrance, transitions between screens, sliding indicators, status pulses, animated flow on links; everything respects `prefers-reduced-motion`.
4. **Shell**: sidebar (Desk, Tunnels with counter, Monitors, Arrangement, Network; "Machines" with a colored dot per machine; Settings at the bottom), routing, main window and tray/menu bar (`V3-Bandeja`).
5. State **store** connected to the `tandemd` IPC (events with subscription only for the visible screen) and **demo mode** with coherent simulated data for every screen and every state (used by screenshots and tests).
6. **⌘K / Ctrl+K palette**, commands only (D15): go to screen, apply scene, measure link, reopen setup, etc. (`F-Paleta`).
7. (From T-126) Demo mode with system combinations: macOS+Windows, Windows+Windows, macOS+macOS, with a screenshot of the two-Windows demo.
8. Screenshot harness: `pnpm shots` takes each screen in demo mode at 1280×860 and compares it with the mockup render (T-125), writing `docs/screenshots/v03/<screen>.png` and its similarity.
9. Remove the old UI (single scene, modes, "requires cable", "Keyboard here").
