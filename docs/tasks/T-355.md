# T-355 — The LaunchAgent update waits for the old agent to exit

## Context

On 2026-11-24, after installing v0.3.3 on the Mac, opening the app rewrote the LaunchAgent (the
version in the plist changed), booted the old agent out and bootstrapped the new one. `bootout`
returns before `tandemd` has exited (it restores the displays it turned off and saves its state), and
the four bootstrap attempts 500 ms apart ran out while launchd still held the service: the agent
stayed down until it was bootstrapped by hand (Mac log: `shutting down (SIGTERM)`, then nothing).

## Scope

- `SystemLaunchd::bootout` waits, up to 15 s, until launchd no longer has the service loaded.
- `SystemLaunchd::bootstrap` retries for up to 10 s.

## Acceptance criteria

- [x] Builds, lints and passes the `launch_agent` tests on macOS.
