# T-332 — `KeepAlive = true` for the LaunchAgent

## Context

Seen on a real Mac with Tandem v0.3.0 (launchd and unified log evidence): System Settings' "Quit & Reopen" sent `tandemd` a Quit AppleEvent, AppKit closed it with exit code 0, and the LaunchAgent's `KeepAlive { SuccessfulExit = false }` left it down (`launchctl print`: `state = not running`, `last exit code = 0`) until a manual `launchctl kickstart`. The exit itself is fixed in `tandemd` separately and the app-side safety net is T-331; this task makes launchd relaunch it on any exit.

## Design check

- `docs/DESIGN.md` and `docs/DECISIONS.md` fix no `KeepAlive` policy (DESIGN §4.2 only says "launchd service"); the only description was in `docs/dev/install-macos.md` and the `plist()` doc-comment. No contradiction.
- Paths where `tandemd` stops on purpose, checked so none relies on "exit 0 = do not relaunch":
  - `tandemd` exits with 0 only on SIGTERM/SIGINT (`daemon::shutdown_signal`); there is no IPC command that stops it (`UiCommand::Kill` is for tunnel processes).
  - App update on macOS: `launch_agent::ensure()` sees a different plist and runs `bootout` then `bootstrap` (`new_version_replaces_and_restarts`, `plist_from_v0_3_0_is_replaced_and_reloaded`). `bootout` unloads the job, so `KeepAlive` does not apply.
  - "Restart agent": `kickstart -k`, relaunched either way.
  - Uninstall on macOS (`docs/dev/install-macos.md`): `launchctl bootout` first.
  - `ui_quit` (`app.rs`) only exits the UI (`app.exit(0)`), never `tandemd`.
  - Logout/shutdown: launchd tears down the whole `gui/<uid>` domain.
  - `tandemd --uninstall` exists only on Windows (not launchd).

## Fix

- `plist()`: `KeepAlive = true` with `ThrottleInterval` 30 s (`THROTTLE_SECS`); doc-comments updated.
- `docs/DECISIONS.md`: dated T-332 line with the reason.
- `docs/dev/install-macos.md`: the new policy, and that stopping it for good means `launchctl bootout`.
- Existing installs: the plist text changes, so the first start of the new app gets `Outcome::Updated` and runs `bootout` + `bootstrap` (one restart of `tandemd`, as with any version change).
