# T-027 — Windows: servicio SYSTEM y escritorio seguro

## Alcance

Modo `--service` de tandemd: servicio SYSTEM que lanza el helper en la sesión activa con token de winlogon y TokenUIAccess, seguimiento de escritorio (OpenInputDesktop/SetThreadDesktop), Ctrl+Alt+Supr con SendSAS. Instalación en Program Files.

## Criterios de aceptación

- [ ] El mouse funciona en un diálogo UAC (prueba manual).
- [ ] Documentar requisitos de firma Authenticode (el usuario decide el certificado).
